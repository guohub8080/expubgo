# {title}

`animateSoftBlink` 是专门用于创建闪烁/淡入淡出效果的预设动画工具。闪烁动画是一种透明度循环变化的效果，常用于吸引注意力、加载状态、错误提示等场景。

---

## 函数签名

```tsx
import { animateSoftBlink } from '@guohub8080/expub-tool/behaviors';

animateSoftBlink({
  maxOpacity?: number,                       // 默认 1：最大透明度（0-1）
  minOpacity?: number,                       // 默认 0.2：最小透明度（0-1）
  onceBlinkDurationSeconds?: number,         // 默认 1.2：一次闪烁时长（秒，变暗 + 变亮各占一半）
  keySplines?: string,                       // 默认 '0.45 0 0.55 1'：缓动曲线（变暗/变亮共用）
  begin?: string,                            // 默认 undefined：开始时机（SMIL begin 字符串）
  loopCount?: number,                        // 默认 0：循环次数（0 = 无限）
  restart?: 'always' | 'whenNotActive' | 'never',
})
```

## 使用示例

### 简单的闪烁效果

```tsx
<svg width="200" height="200">
  <path
    d="M100 20 L120 80 L180 80 L130 120 L150 180 L100 140 L50 180 L70 120 L20 80 L80 80 Z"
    fill="yellow"
  >
    {animateSoftBlink({
      maxOpacity: 1,
      minOpacity: 0.2,
      onceBlinkDurationSeconds: 1.2
    })}
  </path>
</svg>
```

**生成的 SVG 代码：**

```xml
<animate
  attributeName="opacity"
  values="1; 0.2; 1"
  keyTimes="0; 0.5; 1"
  keySplines="0.45 0 0.55 1; 0.45 0 0.55 1"
  dur="1.2s"
  calcMode="spline"
  repeatCount="indefinite"
  fill="remove"
/>
```

**效果**：星星在完全显示和半透明之间循环闪烁

## 常用配方

`animateSoftBlink` 没有预设对象，直接用参数组合出常用效果：

| 效果 | 配方 |
|------|------|
| 轻柔淡入淡出 | `animateSoftBlink({ minOpacity: 0.5, onceBlinkDurationSeconds: 2 })` |
| 标准淡入淡出 | `animateSoftBlink()` |
| 深度淡化 | `animateSoftBlink({ minOpacity: 0.1, onceBlinkDurationSeconds: 2.5 })` |
| 快速闪烁 | `animateSoftBlink({ minOpacity: 0.3, onceBlinkDurationSeconds: 0.8 })` |
| 慢速淡化 | `animateSoftBlink({ onceBlinkDurationSeconds: 3 })` |
| 微弱淡化 | `animateSoftBlink({ minOpacity: 0.7, onceBlinkDurationSeconds: 2 })` |
| 完全消失再出现 | `animateSoftBlink({ minOpacity: 0, onceBlinkDurationSeconds: 1 })` |

---

## 注意事项

### 透明度范围

- `maxOpacity` 和 `minOpacity` 都必须在 `0` 到 `1` 之间
- `maxOpacity` 应该大于 `minOpacity`

### 闪烁效果建议

- **快速闪烁**：适合用于提示、警告
- **慢速闪烁**：适合用于装饰、氛围
- **完全闪烁**（minOpacity: 0）：适合用于强提示
- **轻微闪烁**（minOpacity: 0.7-0.8）：适合用于装饰性元素
