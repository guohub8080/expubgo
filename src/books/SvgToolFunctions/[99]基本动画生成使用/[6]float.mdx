# {title}

`transformFloat` 是专门用于创建浮动效果的预设动画工具。浮动动画是一种上下或左右循环移动的效果，常用于云朵、气泡、悬浮物体等场景。

---

## 函数签名

```tsx
import { transformFloat } from '@guohub8080/expub-tool/behaviors';

transformFloat({
  floatRangeY?: number,                      // 默认 20：Y 轴浮动范围（像素）
  floatRangeX?: number,                      // 默认 0：X 轴浮动范围（像素）
  duration?: number,                         // 默认 4：单次浮动时长（秒）
  keySplines?: string,                       // 默认 '0.24 0 0.24 1'：缓动曲线
  begin?: string,                            // 默认 undefined：开始时机（SMIL begin 字符串）
  loopCount?: number,                        // 默认 0：循环次数（0 = 无限）
})
```

**动画轨迹**：从原点出发 → 浮动到 `(-floatRangeX, -floatRangeY)` → 回到原点，循环往复。

---

## 使用示例

### 简单的上下浮动

```tsx
<svg width="200" height="200">
  <g>
    {transformFloat({
      floatRangeY: 20,  // 上下浮动 20px
      duration: 4       // 4 秒完成一个循环
    })}
    <ellipse cx="100" cy="100" rx="50" ry="30" fill="white" />
    <ellipse cx="120" cy="90" rx="40" ry="25" fill="white" />
    <ellipse cx="80" cy="90" rx="35" ry="20" fill="white" />
  </g>
</svg>
```

**生成的 SVG 代码：**

```xml
<animateTransform
  attributeName="transform"
  type="translate"
  values="0 0; 0 -20; 0 0"
  keyTimes="0; 0.5; 1"
  keySplines="0.24 0 0.24 1; 0.24 0 0.24 1"
  dur="4s"
  calcMode="spline"
  repeatCount="indefinite"
  fill="remove"
  additive="sum"
/>
```

**效果**：云朵在垂直方向上下浮动，循环播放

## 注意事项

### 浮动范围

- **`floatRangeY`**：控制垂直浮动范围（像素）
- **`floatRangeX`**：控制水平浮动范围（像素）
- 两个参数可以同时使用，实现对角线浮动

### 缓动曲线

- 默认使用 `'0.24 0 0.24 1'`（ease-in-out）
- 可以自定义缓动曲线以获得不同的浮动效果
