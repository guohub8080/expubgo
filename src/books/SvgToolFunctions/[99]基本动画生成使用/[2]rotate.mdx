export const title = "旋转动画 rotate"

# {title}

`transformRotate` 是 SVG 旋转动画的生成工具，可以创建 `<animateTransform type="rotate">` 元素。

---

## 函数签名

```tsx
import { transformRotate } from '@guohub8080/expub-tool/smil';

transformRotate({
  initValue?: number,                        // 默认 0：初始角度（度）
  timeline: RotateKeyframe[],                // 必填：时间线段数组（toAbs / toRel 二选一）
  pivot?: [number, number],                  // 默认 [0, 0]：旋转中心 [cx, cy]
  pivots?: [number, number][],               // 逐关键帧旋转中心（长度 = timeline.length + 1），与 pivot 二选一
  begin?: string,                            // 默认 undefined：开始时机（SMIL begin 字符串）
  calcMode?: 'spline' | 'linear' | 'discrete' | 'paced',  // 自动：动画计算模式
  isFreeze?: boolean,                        // 默认 false：是否保持最终状态
  loopCount?: number,                        // 默认 1：循环次数（0 = 无限）
  isAdditive?: boolean,                      // 默认 true：是否累加变换
  restart?: 'always' | 'whenNotActive' | 'never',
  native?: T_NativeAnimateTransform,        // 透传/覆盖原生 animateTransform 属性（最后展开，同名覆盖生成值）
})
```

### RotateKeyframe 类型

```tsx
// toAbs：绝对角度（度）
// toRel：相对增量（相对于上一段结束角度增加的度数）
interface RotateKeyframe {
  toAbs?: number,
  toRel?: number,
  durationSeconds: number,                   // 必填：该段持续时间（秒）
  keySplines?: string,                       // 默认线性 "0 0 1 1"：贝塞尔缓动参数
}
```

### pivot 显式坐标

新 API 不再支持 `'center'` 等快捷位置字符串，旋转中心直接写坐标 `[cx, cy]`。
元素中心按 `x + w/2`、`y + h/2` 自行计算，例如 rect `x=75 y=75 w=50 h=50` 的中心是 `[100, 100]`。

## 使用示例

### 1. 简单的 360 度旋转（围绕元素中心）

```tsx
<svg width="200" height="200">
  <rect x="75" y="75" width="50" height="50" fill="blue">
    {transformRotate({
      initValue: 0,
      pivot: [100, 100],  // rect 中心 = (75 + 25, 75 + 25)
      timeline: [
        { toAbs: 360, durationSeconds: 2 }
      ]
    })}
  </rect>
</svg>
```

**生成的 SVG 代码：**

```xml
<animateTransform
  attributeName="transform"
  type="rotate"
  values="0 100 100; 360 100 100"
  keyTimes="0; 1"
  dur="2s"
  calcMode="linear"
  repeatCount="1"
  fill="remove"
  additive="sum"
/>
```

**效果**：正方形围绕自身中心 (100, 100) 旋转一圈

## pivot 坐标计算

旋转中心直接写 `[cx, cy]` 坐标，按元素位置自行计算。以元素 `x=100, y=50, w=200, h=150` 为例：

| 位置 | 计算方式 | pivot 值 |
|--------|----------|--------|
| 中心 | `[x + w/2, y + h/2]` | `[200, 125]` |
| 顶部中心 | `[x + w/2, y]` | `[200, 50]` |
| 右下角 | `[x + w, y + h]` | `[300, 200]` |
| 左上角 | `[x, y]` | `[100, 50]` |
| SVG 原点 | 固定值 | `[0, 0]`（省略 pivot 即默认） |

需要**逐关键帧切换旋转中心**时（如跨多角色的旋转）使用 `pivots` 数组，长度为 `timeline.length + 1`（initValue 帧在前），与 `pivot` 二选一、同时给出时 `pivots` 优先。

## 注意事项

### isAdditive 属性

- **推荐使用 `isAdditive: true`**（默认）：动画会与其他变换叠加
- 使用 `isAdditive: false`：动画会替换其他变换

### 旋转方向

- **正角度**：顺时针旋转（0 → 90 → 180 → 270 → 360）
- **负角度**：逆时针旋转（0 → -90 → -180 → -270 → -360）

### isFreeze 属性

- **`isFreeze: false`**（默认）：动画结束后回到原始状态
- **`isFreeze: true`**：动画结束后停留在最后一帧
