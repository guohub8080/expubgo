# {title}

`animateOpacity` 是 SVG 透明度动画的生成工具，可以创建 `<animate attributeName="opacity">` 元素。

---

## 函数签名

```tsx
import { animateOpacity } from '@guohub8080/expub-tool/smil';

animateOpacity({
  initValue?: number,                        // 默认 1：初始不透明度（0-1）
  timeline: OpacityKeyframe[],               // 必填：时间线段数组
  begin?: string,                            // 默认 undefined：开始时机（SMIL begin 字符串）
  calcMode?: 'spline' | 'linear' | 'discrete' | 'paced',  // 自动：动画计算模式
  isFreeze?: boolean,                        // 默认 false：是否保持最终状态
  loopCount?: number,                        // 默认 1：循环次数（0 = 无限）
  restart?: 'always' | 'whenNotActive' | 'never',
  native?: T_NativeAnimate,                 // 透传/覆盖原生 animate 属性（最后展开，同名覆盖生成值）
})
```

### OpacityKeyframe 类型

```tsx
interface OpacityKeyframe {
  toAbs: number,                             // 必填：目标不透明度（0-1）
  durationSeconds: number,                   // 必填：该段持续时间（秒）
  keySplines?: string,                       // 默认线性 "0 0 1 1"：贝塞尔缓动参数
}
```

### begin 字符串

`begin` 直接写 SMIL begin 字符串，统一表达「延迟开始」与「事件触发」：
`begin: '2s'`（延迟 2 秒自动开始）、`begin: 'click'`（点击触发）、`begin: 'click+0.5s'`（点击后延迟 0.5 秒）。

---

## 不透明度值说明

| 值 | 效果 | 说明 |
|------|------|------|
| `0` | 完全透明 | 元素不可见 |
| `0.3` | 半透明 | 元素略微可见 |
| `0.5` | 半透明 | 元素半可见 |
| `0.7` | 微透明 | 元素大部分可见 |
| `1` | 完全不透明 | 元素完全可见（默认） |

## 使用示例

### 简单的淡入淡出

```tsx
<svg width="200" height="200">
  <circle cx="100" cy="100" r="30" fill="blue">
    {animateOpacity({
      initValue: 1,
      timeline: [
        { toAbs: 0, durationSeconds: 1 },  // 淡出
        { toAbs: 1, durationSeconds: 1 }   // 淡入
      ]
    })}
  </circle>
</svg>
```

**生成的 SVG 代码：**

```xml
<animate
  attributeName="opacity"
  values="1; 0; 1"
  keyTimes="0; 0.5; 1"
  dur="2s"
  calcMode="linear"
  repeatCount="1"
  fill="remove"
/>
```

**效果**：圆形从完全不透明逐渐消失，然后逐渐显现

## 注意事项

### isFreeze 属性

- **`isFreeze: false`**（默认）：动画结束后回到原始状态
- **`isFreeze: true`**：动画结束后停留在最后一帧

### 不透明度范围

- 不透明度值必须在 `0` 到 `1` 之间
- 超出范围的值会被裁剪（如 `1.5` 变为 `1`，`-0.5` 变为 `0`）

### 性能考虑

- 透明度动画通常性能较好，适合频繁使用
- 无限循环的闪烁效果可能会影响用户体验，谨慎使用

## 完整示例：闪烁的星星

```tsx
import { animateOpacity } from '@guohub8080/expub-tool/smil';

const TwinklingStar = () => {
  return (
    <svg width="100" height="100" viewBox="0 0 100 100">
      {/* 星星形状 */}
      <path
        d="M50 10 L60 40 L90 50 L60 60 L50 90 L40 60 L10 50 L40 40 Z"
        fill="#FFD700"
      >
        {/* 闪烁动画 */}
        {animateOpacity({
          initValue: 1,
          timeline: [
            { toAbs: 0.3, durationSeconds: 0.8 },
            { toAbs: 1, durationSeconds: 0.8 },
            { toAbs: 0.5, durationSeconds: 0.6 },
            { toAbs: 1, durationSeconds: 0.6 }
          ],
          loopCount: 0
        })}
      </path>
    </svg>
  );
};
```

**生成的 SVG 代码：**

```xml
<animate
  attributeName="opacity"
  values="1; 0.3; 1; 0.5; 1"
  keyTimes="0; 0.286; 0.571; 0.857; 1"
  dur="2.8s"
  calcMode="linear"
  repeatCount="indefinite"
  fill="remove"
/>
```
