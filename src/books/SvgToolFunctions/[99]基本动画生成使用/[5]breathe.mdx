# {title}

`transformBreathe` 是专门用于创建呼吸效果的预设动画工具。呼吸动画是一种自动循环的缩放效果，常用于吸引注意力或表示"活跃"状态。

---

## 函数签名

```tsx
import { transformBreathe } from '@guohub8080/expub-tool/behaviors';

transformBreathe({
  fromScale?: number,                        // 默认 1：初始缩放比例
  toScale?: number,                          // 默认 1.1：目标缩放比例
  onceBreatheDurationSeconds?: number,       // 默认 2：单次呼吸时长（秒，放大 + 缩小各占一半）
  pivot: [number, number],                   // 必填：呼吸支点 [cx, cy]
  keySplines?: string,                       // 默认 '0.42 0 0.58 1'：缓动曲线（放大/缩小共用）
  begin?: string,                            // 默认 undefined：开始时机（SMIL begin 字符串）
  loopCount?: number,                        // 默认 0：循环次数（0 = 无限）
})
```

> `pivot` 是必填的显式坐标（如元素中心 `[100, 100]`），不再依赖 CSS `transform-origin` 配合。

---

## 使用示例

### 简单的呼吸效果

```tsx
<svg width="200" height="200">
  <circle cx="100" cy="100" r="30" fill="blue">
    {transformBreathe({ pivot: [100, 100] })}
  </circle>
</svg>
```

**生成的 SVG 代码：**

```xml
<!-- 第一步：平移到支点 -->
<animateTransform
  attributeName="transform"
  type="translate"
  values="100 100; 100 100; 100 100"
  keyTimes="0; 0.5; 1"
  dur="2s"
  calcMode="linear"
  repeatCount="indefinite"
  fill="remove"
  additive="sum"
/>
<!-- 第二步：执行缩放（放大 + 缩小各占一半时长） -->
<animateTransform
  attributeName="transform"
  type="scale"
  values="1 1; 1.1 1.1; 1 1"
  keyTimes="0; 0.5; 1"
  keySplines="0.42 0 0.58 1; 0.42 0 0.58 1"
  dur="2s"
  calcMode="spline"
  repeatCount="indefinite"
  fill="remove"
  additive="sum"
/>
<!-- 第三步：平移回原位置 -->
<animateTransform
  attributeName="transform"
  type="translate"
  values="-100 -100; -100 -100; -100 -100"
  keyTimes="0; 0.5; 1"
  dur="2s"
  calcMode="linear"
  repeatCount="indefinite"
  fill="remove"
  additive="sum"
/>
```

**效果**：圆形在 1.0 到 1.1 倍之间循环缩放，产生呼吸效果（以下示例仅展示 scale 段，前后 translate 包裹同上）

## 常用配方

`transformBreathe` 没有预设对象，直接用参数组合出常用效果：

| 效果 | 配方 |
|------|------|
| 标准呼吸（2 秒） | `transformBreathe({ pivot: [100, 100] })` |
| 快速呼吸（1 秒） | `transformBreathe({ onceBreatheDurationSeconds: 1, toScale: 1.15, pivot: [100, 100] })` |
| 慢速呼吸（3 秒） | `transformBreathe({ onceBreatheDurationSeconds: 3, toScale: 1.08, pivot: [100, 100] })` |
| 轻微呼吸（2.5 秒，小幅度） | `transformBreathe({ onceBreatheDurationSeconds: 2.5, toScale: 1.05, pivot: [100, 100] })` |
| 强烈呼吸（1.5 秒，大幅度） | `transformBreathe({ onceBreatheDurationSeconds: 1.5, toScale: 1.2, pivot: [100, 100] })` |
| 延迟呼吸（延迟 1 秒开始） | `transformBreathe({ begin: '1s', pivot: [100, 100] })` |

## 注意事项

### pivot 属性

- **必填**：显式指定呼吸支点 `[cx, cy]`，通常是元素中心
- 元素中心按 `x + w/2`、`y + h/2` 计算，无需 CSS `transform-origin` 配合

### keySplines 属性

- 单条曲线字符串，放大和缩小两段共用同一条缓动
- 默认 `'0.42 0 0.58 1'`（ease-in-out）

### 与其他动画叠加

`transformBreathe` 内部用 `transformScale` 实现，默认 `isAdditive`，可与其他变换动画叠加。

## 完整示例：呼吸的心形

```tsx
import { transformBreathe } from '@guohub8080/expub-tool/behaviors';

const BreathingHeart = () => {
  return (
    <svg width="100" height="100" viewBox="0 0 100 100">
      {/* 心形（包围盒 x:20 y:10 w:60 h:60 → 中心 [50, 40]） */}
      <path
        d="M50 30 C50 30 20 10 20 30 C20 45 35 55 50 70 C65 55 80 45 80 30 C80 10 50 30 50 30"
        fill="#ef4444"
      >
        {transformBreathe({
          onceBreatheDurationSeconds: 1.2,
          toScale: 1.15,
          keySplines: '0.42 0 1 1',
          pivot: [50, 40]
        })}
      </path>
    </svg>
  );
};
```

**生成的 SVG 代码（scale 段，前后 translate 包裹同前）：**

```xml
<animateTransform
  attributeName="transform"
  type="scale"
  values="1 1; 1.15 1.15; 1 1"
  keyTimes="0; 0.5; 1"
  keySplines="0.42 0 1 1; 0.42 0 1 1"
  dur="1.2s"
  calcMode="spline"
  repeatCount="indefinite"
  fill="remove"
  additive="sum"
/>
```
