export const title = "位移动画 translate"

# {title}

`transformTranslate` 是 SVG 位移动画的生成工具，可以创建 `<animateTransform type="translate">` 元素。

---

## 函数签名

```tsx
import { transformTranslate } from '@guohub8080/expub-tool/smil';

transformTranslate({
  initValue?: { x?: number, y?: number },   // 默认 { x: 0, y: 0 }：初始位移
  timeline: TranslateKeyframe[],            // 必填：时间线段数组（toAbs / toRel 二选一）
  begin?: string,                           // 默认 undefined：开始时机（SMIL begin 字符串）
  calcMode?: 'spline' | 'linear' | 'discrete' | 'paced',  // 自动：动画计算模式
  isFreeze?: boolean,                       // 默认 false：是否保持最终状态
  loopCount?: number,                       // 默认 1：循环次数（0 = 无限）
  isAdditive?: boolean,                     // 默认 true：是否累加变换
  restart?: 'always' | 'whenNotActive' | 'never',
  native?: T_NativeAnimateTransform,        // 透传/覆盖原生 animateTransform 属性（最后展开，同名覆盖生成值）
})
```

### TranslateKeyframe 类型

```tsx
// toAbs：绝对坐标（相对于初始位置的目标位置）
// toRel：相对增量（相对于上一段结束位置的位移）
interface TranslateKeyframe {
  toAbs?: { x?: number, y?: number },
  toRel?: { x?: number, y?: number },
  durationSeconds: number,                  // 必填：该段持续时间（秒）
  keySplines?: string,                      // 默认线性 "0 0 1 1"：贝塞尔缓动参数
}
```

### begin 字符串

`begin` 直接写 SMIL begin 字符串，统一表达「延迟开始」与「事件触发」：

| 写法 | 含义 |
|------|------|
| `begin: '2s'` | 延迟 2 秒自动开始 |
| `begin: 'click'` | 点击触发 |
| `begin: 'click+0.5s'` | 点击后延迟 0.5 秒开始 |

## 使用示例

### 简单的向右平移

```tsx
<svg width="300" height="100">
  <circle cx="50" cy="50" r="20" fill="blue">
    {transformTranslate({
      initValue: { x: 0, y: 0 },
      timeline: [
        { toAbs: { x: 200, y: 0 }, durationSeconds: 2 }
      ]
    })}
  </circle>
</svg>
```

**生成的 SVG 代码：**

```xml
<animateTransform
  attributeName="transform"
  type="translate"
  values="0 0; 200 0"
  keyTimes="0; 1"
  dur="2s"
  calcMode="linear"
  repeatCount="1"
  fill="remove"
  additive="sum"
/>
```

**效果**：圆形从 (50, 50) 向右移动 200px，到达 (250, 50)

### 相对位移模式（toRel）

`toRel` 的每段位移是相对于**上一段结束位置**的增量：

```tsx
{transformTranslate({
  initValue: { x: 0, y: 0 },
  timeline: [
    { toRel: { x: 100, y: 0 }, durationSeconds: 1 },  // 移动到 (100, 0)
    { toRel: { x: 0, y: 0 }, durationSeconds: 1 },    // 保持在 (100, 0)，不移动
    { toRel: { x: 50, y: 0 }, durationSeconds: 1 }    // 移动到 (150, 0)，增量为 (50, 0)
  ]
})}
```

**生成的 SVG 代码：**

```xml
<animateTransform
  attributeName="transform"
  type="translate"
  values="0 0; 100 0; 100 0; 150 0"
  keyTimes="0; 0.333; 0.667; 1"
  dur="3s"
  calcMode="linear"
  repeatCount="1"
  fill="remove"
  additive="sum"
/>
```

## 注意事项

### isAdditive 属性

- **推荐使用 `isAdditive: true`**（默认）：动画会与其他变换叠加
- 使用 `isAdditive: false`：动画会替换其他变换（可能导致冲突）

### isFreeze 属性

- **`isFreeze: false`**（默认）：动画结束后回到原始状态
- **`isFreeze: true`**：动画结束后停留在最后一帧

### calcMode 自动推断

- 任一时间线段提供了 `keySplines` → 自动 `calcMode="spline"`
- 全部未提供 → 自动 `calcMode="linear"`，此时不输出 keySplines 属性
