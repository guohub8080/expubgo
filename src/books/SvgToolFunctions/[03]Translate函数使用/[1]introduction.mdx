# {title}

`transformTranslate` 是 SVG 位移动画的核心生成工具。本文将介绍函数签名、核心概念，并通过基础示例展示其基本用法。

---

## 函数签名

```tsx
import { transformTranslate } from '@guohub8080/expub-tool/smil';

transformTranslate({
  // ===== 必填参数 =====
  timeline: I_AbsRelKeyframe<Partial<I_TranslateValue>>[],  // 必填：时间线段数组

  // ===== 可选参数 =====
  initValue?: { x?: number, y?: number },   // 初始坐标，默认 { x: 0, y: 0 }
  begin?: string,                           // 开始时机：'click' / 'click+0.5s' / '2s'，缺省自动开始
  isAdditive?: boolean,                     // 是否累加变换，默认 true
  calcMode?: 'spline' | 'linear' | 'discrete' | 'paced',  // 动画计算模式，自动
  isFreeze?: boolean,                       // 是否保持最终状态，默认 false
  loopCount?: number,                       // 循环次数（0 = 无限），默认 1
  restart?: 'always' | 'whenNotActive' | 'never',          // 重启策略
  native?: T_NativeAnimateTransform,          // 透传/覆盖原生 animateTransform 属性（最后展开，同名覆盖生成值）
})
```

## 核心概念

### 初始坐标（initValue）

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `x` | `number` | `0` | X 起始坐标（可选） |
| `y` | `number` | `0` | Y 起始坐标（可选） |

### 时间线段

这是最核心的参数，定义动画的每个阶段。每个时间线段通过 `toRel`（相对位移）或 `toAbs`（绝对坐标）指定目标，二者选一。

**`I_AbsRelKeyframe<Partial<I_TranslateValue>>` 类型：**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `toRel` | `Partial<{ x, y }>` | - | 相对位移：相对于上一段终点的增量（可只指定 x 或 y）|
| `toAbs` | `Partial<{ x, y }>` | 上一段位置 | 绝对坐标：目标位置（可只指定 x 或 y）|
| `durationSeconds` | `number` | 必填 | 该段持续时间（秒）|
| `keySplines` | `string` | `"0 0 1 1"` | 贝塞尔缓动参数（可选）|

**基础示例：**

```tsx
import { transformTranslate } from '@guohub8080/expub-tool/smil';

export const BasicUsage = () => {
    return (
        <svg width="300" height="100" viewBox="0 0 300 100">
            <circle cx="50" cy="50" r="20" fill="blue">
                {transformTranslate({
                    initValue: { x: 0, y: 0 },
                    timeline: [
                        { toRel: { x: 200, y: 0 }, durationSeconds: 2 }
                    ]
                })}
            </circle>
        </svg>
    );
};
```

## 常用默认值

`transformTranslate` 的设计让大多数参数都有合理的默认值，让你能快速创建动画。

- **相对位移 toRel**（推荐使用）
  - `toRel` 是相对于上一段终点的增量
  - 更符合直觉："移动多少"
  - 示例：向右 100px，然后向左 100px

- **累加模式**（`isAdditive: true`）
  - 可以与旋转、缩放动画同时进行
  - 自动叠加到其他变换上
