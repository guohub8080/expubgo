# {title}

动画的时序控制是创建复杂动画效果的关键。本文介绍 `transformTranslate` 中与时序相关的三个核心参数：`begin`（延迟与事件触发）、`loopCount` 和 `isFreeze`。

---

## 核心参数

### begin - 延迟与触发时机

控制动画何时开始，用一个字符串同时表达"延迟"和"触发事件"。

**类型**：`string`
**默认值**：缺省（页面加载后自动播放）

**取值形式**：

| 写法 | 含义 |
|------|------|
| `'2s'` | 延迟 2 秒后自动开始 |
| `'click'` | 点击元素后立即开始 |
| `'click+0.5s'` | 点击元素后再延迟 0.5 秒开始 |

**使用场景**：
- 序列动画（多个元素依次出现）
- 入场动画（页面加载后延迟播放）
- 交互式动画（点击触发）

**示例**：

```tsx
transformTranslate({
  initValue: { x: 0, y: 0 },
  timeline: [
    { toRel: { x: 200, y: 0 }, durationSeconds: 2 }
  ],
  begin: '1s'  // 延迟 1 秒后开始
})
```

**效果预览：**

<DelayDemo />

**说明**：三个圆形分别延迟 0s、1s、2s 后开始移动，形成序列动画效果。

---

### loopCount - 循环次数

控制动画播放的次数。

**类型**：`number`
**默认值**：`1`
**特殊值**：`0` 表示无限循环

**使用场景**：
- 呼吸效果（无限循环）
- 重复提示（循环 2-3 次）
- 单次动画（默认值 1）

**示例**：

```tsx
// 播放 1 次（默认）
transformTranslate({
  initValue: { x: 0, y: 0 },
  timeline: [
    { toRel: { x: 200, y: 0 }, durationSeconds: 2 }
  ],
  loopCount: 1
})

// 播放 3 次
transformTranslate({
  initValue: { x: 0, y: 0 },
  timeline: [
    { toRel: { x: 200, y: 0 }, durationSeconds: 2 }
  ],
  loopCount: 3
})

// 无限循环
transformTranslate({
  initValue: { x: 0, y: 0 },
  timeline: [
    { toRel: { x: 200, y: 0 }, durationSeconds: 2 }
  ],
  loopCount: 0
})
```

**效果预览：**

<LoopDemo />

**说明**：三个圆形分别播放 1 次、3 次和无限循环。

---

### isFreeze - 保持最终状态

控制动画结束后是否停留在最后一帧。

**类型**：`boolean`
**默认值**：`false`

**值说明**：
- `false`（默认）：动画结束后回到初始状态
- `true`：动画结束后停留在最终位置

**使用场景**：
- 入场动画（元素移入后保持位置）
- 状态切换（从 A 状态移动到 B 状态）
- 单次动画（不需要回到原位）

**示例**：

```tsx
// 动画结束后回到原位
transformTranslate({
  initValue: { x: 0, y: 0 },
  timeline: [
    { toRel: { x: 200, y: 0 }, durationSeconds: 2 }
  ],
  isFreeze: false  // 默认值
})

// 动画结束后保持最终位置
transformTranslate({
  initValue: { x: 0, y: 0 },
  timeline: [
    { toRel: { x: 200, y: 0 }, durationSeconds: 2 }
  ],
  isFreeze: true
})
```

**效果预览：**

<FreezeDemo />

**说明**：上方圆形动画结束后回到原位，下方圆形保持最终位置。

---

### begin - 点击触发

控制动画是否需要点击元素才开始播放，把事件名写进 `begin` 字符串即可。

**类型**：`string`
**默认值**：缺省

**值说明**：
- 缺省（默认）：页面加载后自动播放
- `'click'`：点击元素后才开始播放

**使用场景**：
- 交互式动画（用户点击触发）
- 按需播放（避免自动播放）
- 游戏元素（点击控制）

**示例**：

```tsx
transformTranslate({
  initValue: { x: 0, y: 0 },
  timeline: [
    { toRel: { x: 200, y: 0 }, durationSeconds: 2 }
  ],
  begin: 'click',
  isFreeze: true  // 通常配合 isFreeze 使用
})
```

**效果预览：**

<ClickTriggerDemo />

**说明**：点击圆形后才开始移动，动画结束后保持最终位置。

## 参数组合

### 组合 1：延迟 + 循环

创建延迟开始的循环动画。

```tsx
transformTranslate({
  initValue: { x: 0, y: 0 },
  timeline: [
    { toRel: { x: 80, y: 0 }, durationSeconds: 1 },
    { toRel: { x: -80, y: 0 }, durationSeconds: 1 }
  ],
  begin: '2s',    // 延迟 2 秒
  loopCount: 0    // 无限循环
})
```

**使用场景**：页面加载后延迟播放的呼吸效果。

---

### 组合 2：点击 + 冻结

创建点击触发的单次动画。

```tsx
transformTranslate({
  initValue: { x: 0, y: 0 },
  timeline: [
    { toRel: { x: 200, y: 0 }, durationSeconds: 2 }
  ],
  begin: 'click',    // 点击触发
  isFreeze: true     // 保持最终位置
})
```

**使用场景**：点击按钮后元素移动到新位置并停留。

---

### 组合 3：延迟 + 点击 + 冻结

创建延迟触发的交互式动画。

```tsx
transformTranslate({
  initValue: { x: 0, y: 0 },
  timeline: [
    { toRel: { x: 200, y: 0 }, durationSeconds: 2 }
  ],
  begin: 'click+1s',  // 点击触发，点击后延迟 1 秒
  isFreeze: true      // 保持最终位置
})
```

**使用场景**：点击后延迟播放的入场动画。

---

### 组合 4：循环 + 冻结

创建循环指定次数后停留的动画。

```tsx
transformTranslate({
  initValue: { x: 0, y: 0 },
  timeline: [
    { toRel: { x: 80, y: 0 }, durationSeconds: 1 },
    { toRel: { x: -80, y: 0 }, durationSeconds: 1 }
  ],
  loopCount: 3,   // 循环 3 次
  isFreeze: true  // 最后停留在最终位置
})
```

**使用场景**：提示动画（摆动 3 次后停止）。

## 使用场景

### 场景 1：入场动画

元素从屏幕外移入，并保持位置。

```tsx
transformTranslate({
  initValue: { x: -200, y: 0 },  // 从左侧屏幕外开始
  timeline: [
    { toRel: { x: 200, y: 0 }, durationSeconds: 1 }
  ],
  begin: '0.5s',  // 延迟 0.5 秒
  isFreeze: true  // 保持最终位置
})
```

---

### 场景 2：呼吸效果

元素持续左右摆动。

```tsx
transformTranslate({
  initValue: { x: 0, y: 0 },
  timeline: [
    { toRel: { x: 10, y: 0 }, durationSeconds: 1 },
    { toRel: { x: -10, y: 0 }, durationSeconds: 1 }
  ],
  loopCount: 0  // 无限循环
})
```

---

### 场景 3：交互式动画

点击元素后触发动画。

```tsx
transformTranslate({
  initValue: { x: 0, y: 0 },
  timeline: [
    { toRel: { x: 150, y: 0 }, durationSeconds: 1.5 }
  ],
  begin: 'click',
  isFreeze: true
})
```

---

### 场景 4：序列动画

多个元素依次出现。

```tsx
// 第一个元素
transformTranslate({
  initValue: { x: 0, y: 0 },
  timeline: [
    { toRel: { x: 100, y: 0 }, durationSeconds: 1 }
  ],
  begin: '0s',
  isFreeze: true
})

// 第二个元素
transformTranslate({
  initValue: { x: 0, y: 0 },
  timeline: [
    { toRel: { x: 100, y: 0 }, durationSeconds: 1 }
  ],
  begin: '0.5s',  // 延迟 0.5 秒
  isFreeze: true
})

// 第三个元素
transformTranslate({
  initValue: { x: 0, y: 0 },
  timeline: [
    { toRel: { x: 100, y: 0 }, durationSeconds: 1 }
  ],
  begin: '1s',    // 延迟 1 秒
  isFreeze: true
})
```

## 注意事项

### isFreeze 与 loopCount 的关系

当 `loopCount > 1` 或 `loopCount = 0`（无限循环）时，`isFreeze` 参数的效果：

- **loopCount = 1**：`isFreeze: true` 会停留在最终位置
- **loopCount > 1**：`isFreeze: true` 会在最后一次循环结束后停留
- **loopCount = 0**：`isFreeze` 参数无效（因为动画永不结束）

```tsx
// ✅ 有效：单次动画 + isFreeze
transformTranslate({
  timeline: [...],
  loopCount: 1,
  isFreeze: true  // 动画结束后停留
})

// ⚠️ 注意：无限循环 + isFreeze
transformTranslate({
  timeline: [...],
  loopCount: 0,
  isFreeze: true  // isFreeze 无效，因为动画永不结束
})
```

---

### begin 的限制

- 只能点击一次触发动画
- 如果需要重复点击触发，需要使用 JavaScript 控制
- 点击区域是整个 SVG 元素

---

### begin 延迟的计算

- 延迟数字是相对于页面加载或点击事件的
- 如果使用 `begin: 'click+1s'`，1s 是点击后的延迟
- 多个元素的 `begin` 延迟可以不同，实现序列动画

---

## 总结

| 参数 | 默认值 | 说明 | 常用场景 |
|------|--------|------|----------|
| `begin` | 缺省 | 延迟/触发时机（'2s'、'click'、'click+0.5s'） | 序列动画、交互式动画 |
| `loopCount` | `1` | 循环次数（0=无限） | 呼吸效果、重复提示 |
| `isFreeze` | `false` | 保持最终状态 | 入场动画、状态切换 |

**推荐组合**：
- 入场动画：`begin: '0.5s'` + `isFreeze`
- 呼吸效果：`loopCount: 0`
- 交互式动画：`begin: 'click'` + `isFreeze`
- 序列动画：不同的 `begin` 延迟值
