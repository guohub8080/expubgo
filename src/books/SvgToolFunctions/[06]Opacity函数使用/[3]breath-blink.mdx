呼吸和闪烁是基于循环透明度的常见动画效果。本文介绍如何创建这些循环动画。

---

## 呼吸效果（Breathe）

呼吸效果是指元素在两个透明度之间平滑循环变化，类似呼吸的节奏。

### 基本用法

**代码示例：**

```tsx
import { animateOpacity } from "@guohub8080/expub-tool/smil";

<svg width="200" height="200" viewBox="0 0 200 200">
  <circle cx="100" cy="100" r="40" fill="blue">
    {animateOpacity({
      initValue: 1,
      timeline: [
        { toAbs: 0.3, durationSeconds: 2 },  // 淡出到 30%
        { toAbs: 1, durationSeconds: 2 }     // 淡入回 100%
      ],
      loopCount: 0  // 无限循环
    })}
  </circle>
</svg>
```

**效果预览：**

<Breathe />

**说明**：圆形在 30% 和 100% 透明度之间循环

### 常用配方：呼吸

往返两段 timeline + `loopCount: 0`：

```tsx
import { animateOpacity } from "@guohub8080/expub-tool/smil";

// 呼吸效果（最低30%，单程2秒）
animateOpacity({
  initValue: 1,
  timeline: [
    { toAbs: 0.3, durationSeconds: 2 },
    { toAbs: 1, durationSeconds: 2 },
  ],
  loopCount: 0,
})

// 自定义参数（最低20%，单程3秒）
animateOpacity({
  initValue: 1,
  timeline: [
    { toAbs: 0.2, durationSeconds: 3 },
    { toAbs: 1, durationSeconds: 3 },
  ],
  loopCount: 0,
})
```

## 闪烁效果（Blink）

闪烁效果是指元素快速地在透明和不透明之间切换。

### 基本用法

**代码示例：**

```tsx
import { animateOpacity } from "@guohub8080/expub-tool/smil";

<svg width="200" height="200" viewBox="0 0 200 200">
  <circle cx="100" cy="100" r="40" fill="blue">
    {animateOpacity({
      initValue: 1,
      timeline: [
        { toAbs: 0, durationSeconds: 0.5 },  // 0.5秒淡出
        { toAbs: 1, durationSeconds: 0.5 }   // 0.5秒淡入
      ],
      loopCount: 0  // 无限循环
    })}
  </circle>
</svg>
```

**效果预览：**

<Blink />

**说明**：圆形每秒闪烁一次

### 常用配方：闪烁

```tsx
import { animateOpacity } from "@guohub8080/expub-tool/smil";

// 闪烁效果（3次闪烁，总时长1.5秒，单次明/暗各0.25秒）
animateOpacity({
  initValue: 1,
  timeline: [
    { toAbs: 0, durationSeconds: 0.25 },
    { toAbs: 1, durationSeconds: 0.25 },
    { toAbs: 0, durationSeconds: 0.25 },
    { toAbs: 1, durationSeconds: 0.25 },
    { toAbs: 0, durationSeconds: 0.25 },
    { toAbs: 1, durationSeconds: 0.25 },
  ],
})

// 自定义参数（5次闪烁，总时长2秒，单次明/暗各0.2秒）
animateOpacity({
  initValue: 1,
  timeline: [
    { toAbs: 0, durationSeconds: 0.2 },
    { toAbs: 1, durationSeconds: 0.2 },
    // ……共 5 组
  ],
})

// 慢闪烁（2秒一个明暗循环，无限重复，暗到20%）
animateOpacity({
  initValue: 1,
  timeline: [
    { toAbs: 0.2, durationSeconds: 1 },
    { toAbs: 1, durationSeconds: 1 },
  ],
  loopCount: 0,
})
```

## 心跳效果（Heartbeat）

心跳效果模拟心脏跳动的节奏：快速连续两次跳动后停顿。

**代码示例：**

```tsx
import { animateOpacity } from "@guohub8080/expub-tool/smil";

<svg width="200" height="200" viewBox="0 0 200 200">
  <circle cx="100" cy="100" r="40" fill="red">
    {animateOpacity({
      initValue: 1,
      timeline: [
        { toAbs: 0.6, durationSeconds: 0.2 },  // 第一次跳动
        { toAbs: 1, durationSeconds: 0.2 },
        { toAbs: 0.6, durationSeconds: 0.2 },  // 第二次跳动
        { toAbs: 1, durationSeconds: 0.2 },
        { toAbs: 1, durationSeconds: 0.8 }     // 停顿（保持当前透明度）
      ],
      loopCount: 0
    })}
  </circle>
</svg>
```

**效果预览：**

<Heartbeat />

**说明**：红色圆形模拟心跳节奏

## 幽灵效果（Ghost）

幽灵效果是元素在半透明和不透明之间缓慢循环，营造飘渺的感觉。

**代码示例：**

```tsx
import { animateOpacity } from "@guohub8080/expub-tool/smil";

<svg width="200" height="200" viewBox="0 0 200 200">
  <circle cx="100" cy="100" r="40" fill="purple">
    {animateOpacity({
      initValue: 1,
      timeline: [
        { toAbs: 0.5, durationSeconds: 1.5 },  // 半透明
        { toAbs: 1, durationSeconds: 1.5 }     // 不透明
      ],
      loopCount: 0
    })}
  </circle>
</svg>
```

**效果预览：**

<Ghost />

**说明**：紫色圆形营造幽灵飘渺效果

### 常用配方：幽灵

```tsx
import { animateOpacity } from "@guohub8080/expub-tool/smil";

// 幽灵效果（单程1.5秒）
animateOpacity({
  initValue: 1,
  timeline: [
    { toAbs: 0.5, durationSeconds: 1.5 },
    { toAbs: 1, durationSeconds: 1.5 },
  ],
  loopCount: 0,
})

// 自定义单程3秒
animateOpacity({
  initValue: 1,
  timeline: [
    { toAbs: 0.5, durationSeconds: 3 },
    { toAbs: 1, durationSeconds: 3 },
  ],
  loopCount: 0,
})
```

## 实用技巧

### 脉冲效果（快速呼吸）

```tsx
import { animateOpacity } from "@guohub8080/expub-tool/smil";

// 0.5秒完成一次呼吸（暗到40%再回满）
animateOpacity({
  initValue: 1,
  timeline: [
    { toAbs: 0.4, durationSeconds: 0.25 },
    { toAbs: 1, durationSeconds: 0.25 },
  ],
  loopCount: 0,
})
```

### 波浪渐变（多段过渡）

```tsx
import { animateOpacity } from "@guohub8080/expub-tool/smil";

// 4秒完成多段波浪渐变（每段1秒）
animateOpacity({
  initValue: 1,
  timeline: [
    { toAbs: 0.3, durationSeconds: 1 },
    { toAbs: 0.7, durationSeconds: 1 },
    { toAbs: 0.3, durationSeconds: 1 },
    { toAbs: 1, durationSeconds: 1 },
  ],
  loopCount: 0,
})
```

### 淡入停留淡出循环

```tsx
import { animateOpacity } from "@guohub8080/expub-tool/smil";

// 淡入1秒 -> 停留2秒 -> 淡出1秒，循环
animateOpacity({
  initValue: 0,
  timeline: [
    { toAbs: 1, durationSeconds: 1 },  // 淡入
    { toAbs: 1, durationSeconds: 2 },  // 停留2秒（保持当前透明度）
    { toAbs: 0, durationSeconds: 1 },  // 淡出
  ],
  loopCount: 0,
})
```
