# {title}

淡入（Fade In）和淡出（Fade Out）是最基础的透明度动画效果。本文介绍如何使用 `animateOpacity` 创建这两种效果。

---

## 淡入（Fade In）

淡入是指元素从透明逐渐变为不透明。

### 基本用法

**代码示例：**

```tsx
import { animateOpacity } from "@guohub8080/expub-tool/smil";

<svg width="200" height="200" viewBox="0 0 200 200">
  <circle cx="100" cy="100" r="40" fill="blue">
    {animateOpacity({
      initValue: 0,          // 从完全透明开始
      timeline: [
        { toAbs: 1, durationSeconds: 2 }  // 2秒淡入到不透明
      ],
      isFreeze: true         // 保持最终状态
    })}
  </circle>
</svg>
```

**效果预览：**

<FadeIn />

**说明**：圆形从完全透明淡入到完全不透明

### 常用配方：淡入

直接用 timeline 表达「淡入」，时长自己写：

```tsx
import { animateOpacity } from "@guohub8080/expub-tool/smil";

// 淡入（1秒）
animateOpacity({
  initValue: 0,
  timeline: [{ toAbs: 1, durationSeconds: 1 }],
  isFreeze: true,
})

// 淡入（2秒）
animateOpacity({
  initValue: 0,
  timeline: [{ toAbs: 1, durationSeconds: 2 }],
  isFreeze: true,
})
```

## 淡出（Fade Out）

淡出是指元素从不透明逐渐变为透明。

### 基本用法

**代码示例：**

```tsx
import { animateOpacity } from "@guohub8080/expub-tool/smil";

<svg width="200" height="200" viewBox="0 0 200 200">
  <circle cx="100" cy="100" r="40" fill="blue">
    {animateOpacity({
      initValue: 1,          // 从不透明开始
      timeline: [
        { toAbs: 0, durationSeconds: 2 }  // 2秒淡出到透明
      ],
      isFreeze: true         // 保持最终状态
    })}
  </circle>
</svg>
```

**效果预览：**

<FadeOut />

**说明**：圆形从完全不透明淡出到完全透明

### 常用配方：淡出

```tsx
import { animateOpacity } from "@guohub8080/expub-tool/smil";

// 淡出（1秒）
animateOpacity({
  initValue: 1,
  timeline: [{ toAbs: 0, durationSeconds: 1 }],
  isFreeze: true,
})

// 淡出（2秒）
animateOpacity({
  initValue: 1,
  timeline: [{ toAbs: 0, durationSeconds: 2 }],
  isFreeze: true,
})
```

---

## isFreeze 参数说明

| 值 | 效果 |
|------|------|
| `true` | 动画结束后保持最终状态 |
| `false` | 动画结束后恢复初始状态 |

**淡入动画通常使用 `isFreeze: true`**，让元素保持可见状态。

---

## 常见时长

| 效果 | 推荐时长 |
|------|----------|
| 快速 | 0.3 - 0.5 秒 |
| 正常 | 1 - 1.5 秒 |
| 缓慢 | 2 - 3 秒 |

## 实用技巧

### 渐显效果（延迟后淡入）

```tsx
{animateOpacity({
  initValue: 0,
  timeline: [
    { toAbs: 1, durationSeconds: 1 }
  ],
  begin: "0.5s",     // 延迟0.5秒后开始
  isFreeze: true
})}
```

### 线性淡入（匀速）

```tsx
{animateOpacity({
  initValue: 0,
  timeline: [
    {
      toAbs: 1,
      durationSeconds: 2,
      keySplines: '0 0 1 1'  // 线性缓动
    }
  ],
  isFreeze: true
})}
```

### 快速淡入淡出

```tsx
// 快速淡入（0.3秒）
animateOpacity({
  initValue: 0,
  timeline: [{ toAbs: 1, durationSeconds: 0.3 }],
  isFreeze: true,
})

// 快速淡出（0.3秒）
animateOpacity({
  initValue: 1,
  timeline: [{ toAbs: 0, durationSeconds: 0.3 }],
  isFreeze: true,
})
```
