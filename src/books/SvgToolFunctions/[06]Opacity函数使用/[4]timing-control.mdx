# {title}

时序控制参数让你精确控制透明度动画的播放时机、循环次数和结束状态。

---

## 延迟开始（begin）

`begin` 参数是一个字符串，让动画在指定时间后才开始播放。

### 基本用法

**代码示例：**

```tsx
import { animateOpacity } from "@guohub8080/expub-tool/smil";

<svg width="200" height="200" viewBox="0 0 200 200">
  <circle cx="100" cy="100" r="40" fill="blue">
    {animateOpacity({
      initValue: 1,
      timeline: [
        { toAbs: 0, durationSeconds: 1 }
      ],
      begin: "1s"  // 延迟1秒后开始
    })}
  </circle>
</svg>
```

**效果预览：**

<DelayDemo />

**说明**：圆形等待1秒后才开始淡出

### 常用配方：延迟淡入

```tsx
import { animateOpacity } from "@guohub8080/expub-tool/smil";

// 延迟0.5秒后淡入1秒
animateOpacity({
  initValue: 0,
  timeline: [{ toAbs: 1, durationSeconds: 1 }],
  begin: "0.5s",
  isFreeze: true,
})

// 自定义延迟和时长（延迟1秒，淡入2秒）
animateOpacity({
  initValue: 0,
  timeline: [{ toAbs: 1, durationSeconds: 2 }],
  begin: "1s",
  isFreeze: true,
})
```

## 循环播放（loopCount）

`loopCount` 参数控制动画循环播放的次数。

### 参数说明

| 值 | 效果 |
|------|------|
| `1` | 播放一次（默认）|
| `2` | 播放两次 |
| `0` | 无限循环 |

### 循环示例

**代码示例：**

```tsx
import { animateOpacity } from "@guohub8080/expub-tool/smil";

<svg width="200" height="200" viewBox="0 0 200 200">
  <circle cx="100" cy="100" r="40" fill="blue">
    {animateOpacity({
      initValue: 1,
      timeline: [
        { toAbs: 0, durationSeconds: 1 },
        { toAbs: 1, durationSeconds: 1 }
      ],
      loopCount: 0  // 无限循环
    })}
  </circle>
</svg>
```

**效果预览：**

<LoopDemo />

**说明**：圆形持续循环淡入淡出

### 往返循环配方

往返循环写成「去 + 回」两段 timeline，配合 `loopCount: 0`：

```tsx
import { animateOpacity } from "@guohub8080/expub-tool/smil";

// 往返循环（0.3 ↔ 1，单程2秒）
animateOpacity({
  initValue: 1,
  timeline: [
    { toAbs: 0.3, durationSeconds: 2 },  // 去程：淡到 0.3
    { toAbs: 1, durationSeconds: 2 },    // 回程：回到 1
  ],
  loopCount: 0,
})
```

## 保持状态（isFreeze）

`isFreeze` 参数控制动画结束后是否保持最终状态。

### 参数说明

| 值 | 效果 |
|------|------|
| `true` | 保持最终状态 |
| `false` | 恢复初始状态（默认）|

### 冻结示例

**代码示例：**

```tsx
import { animateOpacity } from "@guohub8080/expub-tool/smil";

<svg width="200" height="200" viewBox="0 0 200 200">
  <circle cx="100" cy="100" r="40" fill="blue">
    {animateOpacity({
      initValue: 1,
      timeline: [
        { toAbs: 0, durationSeconds: 2 }
      ],
      isFreeze: true  // 保持透明状态
    })}
  </circle>
</svg>
```

**效果预览：**

<FreezeDemo />

**说明**：圆形淡出后保持透明，不会恢复

### 何时使用 isFreeze

**需要 isFreeze：**
- 淡入后保持显示
- 淡出后隐藏
- 单次过渡效果

**不需要 isFreeze：**
- 循环动画
- 提示性动画

## 保持透明度

通过在时间线中写一段 `toAbs` 等于当前值的段，可以保持当前透明度一段时间。

**代码示例：**

```tsx
{animateOpacity({
  initValue: 1,
  timeline: [
    { toAbs: 0, durationSeconds: 1 },    // 淡出
    { toAbs: 0, durationSeconds: 2 },    // 保持透明2秒
    { toAbs: 1, durationSeconds: 1 }     // 淡入
  ],
  loopCount: 0
})}
```

**说明**：淡出 -> 停留2秒 -> 淡入，循环

## 参数组合示例

### 延迟 + 循环

```tsx
{animateOpacity({
  initValue: 1,
  timeline: [
    { toAbs: 0.3, durationSeconds: 1.5 },
    { toAbs: 1, durationSeconds: 1.5 }
  ],
  begin: "1s",     // 延迟1秒开始
  loopCount: 0     // 无限循环
})}
```

### 延迟 + 冻结

```tsx
{animateOpacity({
  initValue: 0,
  timeline: [
    { toAbs: 1, durationSeconds: 1 }
  ],
  begin: "0.5s",   // 延迟0.5秒
  isFreeze: true   // 保持不透明
})}
```

### 多次循环 + 冻结

```tsx
{animateOpacity({
  initValue: 1,
  timeline: [
    { toAbs: 0.2, durationSeconds: 0.5 },
    { toAbs: 1, durationSeconds: 0.5 }
  ],
  loopCount: 3,    // 循环3次
  isFreeze: true   // 保持最终状态
})}
```
