# {title}

SVG 动画组件通常需要统一尺寸的图片。手动测量每张图片并填入宽高既低效又容易出错，`@guohub8080/expub-tool/utils` 提供了两个工具自动获取图片尺寸：

- **`useImgSize`** - React Hook（组件内使用，响应式更新）
- **`getImgSizeAsync`** - 纯 Promise 函数（非组件场景使用）

```typescript
import { useImgSize, getImgSizeAsync } from '@guohub8080/expub-tool/utils';
```

## 设计理念

- 多数组件默认以**第一张图**为基准获取尺寸
- 优先使用手动指定的 `viewBoxW` 或 `viewBoxH`（覆盖自动获取）
- 避免重复的手动测量工作，提高开发效率

## useImgSize（推荐，组件内使用）

### 函数签名

```typescript
useImgSize(url: string, w?: number, h?: number): {
  size: { w: number, h: number },  // 当前尺寸，加载成功后自动更新
  loading: boolean,                // 是否正在加载
  error: boolean                   // 是否加载失败
}
```

**⚠️ 重要：这是一个响应式 Hook 函数**

同步返回初始值，同时后台异步加载图片真实尺寸。当图片加载完成时，`size` 会自动更新，触发组件重新渲染。

### 优先级

1. **传入的 w/h（任一 > 0）**：直接使用，不发起网络请求
2. **未传入**：异步加载图片获取原始尺寸
3. **加载失败**：保持默认值 `{ w: 0, h: 0 }`

### 使用示例

```tsx
function MyComponent() {
  // 手动指定宽高：直接返回，无网络请求
  const { size } = useImgSize(pic1, 300, 200);
  // size => { w: 300, h: 200 }

  return <image href={pic1} width={size.w} height={size.h} />;
}
```

```tsx
function MyComponent() {
  // 不指定宽高：异步获取
  const { size, loading } = useImgSize(pic1);
  // 首次渲染：size => { w: 0, h: 0 }
  // 图片加载完成后：size => { w: 实际宽度, h: 实际高度 }，组件自动重渲染

  if (loading) return <LoadingIcon />;

  return <image href={pic1} width={size.w} height={size.h} />;
}
```

**渲染流程：**

1. 初次渲染：`size = { w: 0, h: 0 }`
2. 异步加载图片...
3. 加载完成后：`size` 自动更新为实际尺寸
4. 触发组件重新渲染，显示正确尺寸

## getImgSizeAsync（非组件场景）

`useImgSize` 是 Hook，只能在组件内使用。在普通函数、loader、脚本等场景用 Promise 版本：

### 函数签名

```typescript
getImgSizeAsync(url: string): Promise<{
  w: number;         // 图片原始宽度（naturalWidth）
  h: number;         // 图片原始高度（naturalHeight）
  status: string;    // "success" | "error"
  isSuccess: boolean // 是否成功获取
}>
```

### 使用示例

```typescript
const result = await getImgSizeAsync('pic1.jpg');
if (result.isSuccess) {
  console.log(`图片尺寸: ${result.w} x ${result.h}`);
} else {
  console.error('获取图片尺寸失败');
}
```

**注意**：`getImgSizeAsync` 只负责获取，没有「手动值优先」的覆盖逻辑——需要覆盖语义时自行判断传入的 w/h，或直接在组件里用 `useImgSize(url, w, h)`。

## 实际应用场景

在组件中动态设置 SVG viewBox（以第一张图为基准）

```tsx
import { defaultTo } from 'es-toolkit/compat';
import { useImgSize } from '@guohub8080/expub-tool/utils';

const AnyPush = (props: {
    pics?: { url: string }[]
    viewBoxW?: number  // 手动指定宽度（覆盖自动获取）
    viewBoxH?: number  // 手动指定高度（覆盖自动获取）
}) => {
    // 关键逻辑：
    // 1. 使用第一张图的 URL 作为基准
    // 2. 如果提供了 viewBoxW/H，优先使用（覆盖），不发请求
    // 3. 否则自动获取第一张图的实际尺寸
    const { size: canvasSize } = useImgSize(
        defaultTo(props.pics?.[0]?.url, ''),
        props.viewBoxW,
        props.viewBoxH
    );

    return (
        <SvgEx
            viewBox={`0 0 ${canvasSize.w} ${canvasSize.h}`}
            width="100%"
        >
            {/* 所有图片都会按这个 viewBox 尺寸显示 */}
        </SvgEx>
    );
}
```

**使用示例：**

```tsx
// 场景1: 自动获取第一张图尺寸
<AnyPush pics={[
    { url: "pic1.jpg" },  // 作为基准
    { url: "pic2.jpg" },
]} />

// 场景2: 手动指定统一尺寸（推荐）
<AnyPush
    viewBoxW={375}
    viewBoxH={667}
    pics={[
        { url: "pic1.jpg" },
        { url: "pic2.jpg" },
    ]}
/>
```

## 最佳实践与注意事项

- ✅ **推荐做法**：手动指定 viewBoxW/H（性能最好，避免响应式更新）
- 📐 **核心价值**：统一所有图片尺寸，无需逐个测量
- 🎯 **设计模式**：以第一张图为基准，其他图自动适配
- ⚠️ **异步特性**：`useImgSize` 是响应式 Hook，返回值会随图片加载完成而自动更新
- 🔄 **渲染影响**：自动获取时，初次渲染 `size` 为 `{ w: 0, h: 0 }`，加载后触发重渲染
- 💡 **组件外取尺寸**：用 `getImgSizeAsync`（async/await），失败时返回 `{ w: 0, h: 0, isSuccess: false }`
