# {title}

`elementBounds` 用于描述 SVG 元素的位置和尺寸，配合 `getOriginNumByText` 函数自动计算变换支点（pivot）坐标。这些工具都从 `@guohub8080/expub-tool/utils` 导入：

```typescript
import {
  getElementBounds,       // 规范化边界对象（补全缺省的 x/y）
  getOriginNumByText,     // 快捷位置名 → [x, y] 坐标
  type ElementBoundsType,
  type OriginPosition
} from '@guohub8080/expub-tool/utils';
```

> 💡 **先看这里**：新动画 API（`transformScale` / `transformRotate`）已改为**显式 `pivot` 坐标参数**，多数场景不再需要运行时求 bounds——直接把元素中心或锚点坐标写进 `pivot` 即可。`getElementBounds` / `getOriginNumByText` 适合需要程序化计算 pivot（例如根据 props 动态求坐标）或做图形对齐、锚点计算的场景。

## 什么是 ElementBounds？

`ElementBoundsType` 是一个描述元素边界的类型，包含以下属性：

- `x?`: 元素左上角 X 坐标（可选，默认 0）
- `y?`: 元素左上角 Y 坐标（可选，默认 0）
- `w`: 元素宽度（必填）
- `h`: 元素高度（必填）

```typescript
type ElementBoundsType = {
  x?: number;  // 左上角 X 坐标，默认 0
  y?: number;  // 左上角 Y 坐标，默认 0
  w: number;   // 宽度（必填）
  h: number;   // 高度（必填）
}
```

`getElementBounds` 会把可能缺少 `x`/`y` 的边界对象补全为完整对象（缺省填 0），方便后续计算：

```typescript
getElementBounds({ w: 100, h: 200 })  // => { x: 0, y: 0, w: 100, h: 200 }
```

## 为什么需要 ElementBounds？

SVG 的旋转、缩放等变换默认以坐标原点 `(0, 0)` 为中心。但通常我们希望：

- ✅ **以元素自身的中心**为变换支点
- ✅ **以元素的某个角落或边缘**为变换支点

`elementBounds` 提供元素的位置和尺寸信息，让 `getOriginNumByText` 能够**自动计算**出正确的支点坐标，再交给动画 API 的 `pivot` 参数使用。

## 完整示例：pivot 是如何工作的？

### 基本用法

```tsx
import { transformScale } from '@guohub8080/expub-tool/smil';

<svg viewBox="0 0 400 200">
  {/* 一个图片，位置在 (100, 50)，尺寸 80x80，中心点即 (140, 90) */}
  <image x="100" y="50" width="80" height="80" href="pic.png">
    {transformScale({
      pivot: [140, 90],  // ← 元素中心：x + w/2 = 140，y + h/2 = 90
      timeline: [
        { durationSeconds: 1, toAbs: 1.5 },
        { durationSeconds: 1, toAbs: 1 }
      ],
      loopCount: 0
    })}
  </image>
</svg>
```

### pivot 内部计算过程

`transformScale` 内部用「平移到支点 → 缩放 → 平移回去」三个 `animateTransform` 保证绕支点缩放：

```javascript
// 1. 根据 pivot 计算三个元素的 values
// 第一个：平移到支点
values="140 90;140 90;140 90"

// 第二个：缩放
values="1 1;1.5 1.5;1 1"

// 第三个：平移回去
values="-140 -90;-140 -90;-140 -90"
```

### 可视化说明

```
SVG 坐标系：
┌─────────────────────────────────────────┐
│ (0,0)                                   │
│                                         │
│         ┌─────────────┐                 │
│         │             │                 │
│         │   图片      │  80x80          │
│         │   中心点     │                 │
│         │    ●        │                 │
│         └─────────────┘                 │
│       ↑(100,50)                         │
│                                         │
│       支点坐标：(140, 90)                │
│       = (100 + 40, 50 + 40)             │
└─────────────────────────────────────────┘
```

### 关键点：pivot 必须匹配元素的实际位置

```tsx
// ✅ 正确：pivot 和 image 的实际中心一致
<image x="100" y="50" width="80" height="80">
  {transformScale({
    pivot: [140, 90],  // = (100 + 80/2, 50 + 80/2)，匹配！
    timeline: [{ durationSeconds: 1, toAbs: 1.5 }]
  })}
</image>

// ❌ 错误：pivot 不匹配
<image x="100" y="50" width="80" height="80">
  {transformScale({
    pivot: [40, 40],  // 不是这个元素的中心！缩放支点会错
    timeline: [{ durationSeconds: 1, toAbs: 1.5 }]
  })}
</image>
```

### 不同支点的效果对比

同样一个位于 `(100, 50)`、尺寸 `80x80` 的元素，不同的 `pivot` 会产生不同的效果：

```tsx
// pivot: [140, 90]（中心）→ 元素从自己的中心放大缩小
// pivot: [100, 50]（左上角）→ 元素从左上角放大，向右下角扩散
// pivot: [180, 130]（右下角）→ 元素从右下角放大，向左上角扩散
```

## 支持的快捷位置（OriginPosition）

`getOriginNumByText` 函数支持 10 种快捷位置，可以直接算出 pivot 坐标：

假设元素位置为 `x: 50, y: 70`，尺寸为 `w: 80, h: 60`：

| 位置名称 | 计算公式 | 示例结果 |
|----------|----------|----------|
| topLeft | [x, y] | [50, 70] |
| topCenter | [x + w/2, y] | [90, 70] |
| topRight | [x + w, y] | [130, 70] |
| centerLeft | [x, y + h/2] | [50, 100] |
| **center** | [x + w/2, y + h/2] | **[90, 100]** |
| centerRight | [x + w, y + h/2] | [130, 100] |
| bottomLeft | [x, y + h] | [50, 130] |
| bottomCenter | [x + w/2, y + h] | [90, 130] |
| bottomRight | [x + w, y + h] | [130, 130] |
| origin | [0, 0] | [0, 0] |

配合动画 API 使用：

```typescript
import { transformScale } from '@guohub8080/expub-tool/smil';
import { getOriginNumByText } from '@guohub8080/expub-tool/utils';

// 程序化求中心支点，等价于手写 pivot: [140, 90]
transformScale({
  pivot: getOriginNumByText('center', { x: 100, y: 50, w: 80, h: 80 }),
  timeline: [{ durationSeconds: 1, toAbs: 1.5 }]
})
```

## 新 API 已用显式 pivot，不再需要 CSS 辅助

旧版方案需要 CSS `transform-origin` + `transform-box` 辅助样式配合实现中心变换；新动画 API（`transformScale` / `transformRotate`）直接通过 `pivot` 坐标在 SMIL 层完成支点控制：

- ✅ **纯 SVG 实现**，不依赖 CSS 支持，微信内核兼容性更好
- ✅ `transformScale` 的 `pivot` 为**必填**——每个缩放都必须明确支点
- ✅ `transformRotate` 的 `pivot` 可选（缺省绕原点），还支持 `pivots` 数组实现多支点旋转
- ✅ `transformTranslate` / `transformSkewX` / `transformSkewY` 无 pivot 参数（不需要支点）

## 哪些动画使用 pivot？

- **缩放动画（transformScale）** - `pivot` 必填，指定缩放支点
- **旋转动画（transformRotate）** - `pivot` 可选，指定旋转支点；`pivots` 支持多支点路径式旋转
- 斜切（transformSkewX/Y）、位移（transformTranslate）不使用 pivot

## 两种提供 pivot 的方式对比

| 方式 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| 手写 `pivot: [x, y]` | ✅ 零依赖、一眼可读<br/>✅ 纯静态坐标 | ⚠️ 元素位置变化时要手动同步 | **推荐使用**（静态排版） |
| `getOriginNumByText(pos, bounds)` | ✅ 程序化计算<br/>✅ 支持 10 种快捷位置 | ⚠️ 需要提供位置和尺寸信息 | 元素位置由 props 动态决定的场景 |
