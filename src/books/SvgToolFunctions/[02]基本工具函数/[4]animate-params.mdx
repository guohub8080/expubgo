# {title}

介绍通用参数 additive、freeze、动画如何重播，以及各动画函数的推荐设置。所有动画函数从 `@guohub8080/expub-tool/smil` 导入。

## additive（叠加）

控制该动画是否与元素现有的 transform/属性动画进行叠加。

- **sum**：与现有变换叠加（推荐用于 transform 类动画的组合，例如多段 translate/scale/rotate 同时进行）
- **默认建议**：transform 类函数（transformTranslate/transformScale/transformRotate 等）的 `isAdditive` 默认为 `true`，即默认叠加。调用方通常无需显式设置

```xml
<!-- 多段变换组合时使用 additive="sum" -->
<animateTransform type="translate" additive="sum" ... />
<animateTransform type="scale"      additive="sum" ... />
<animateTransform type="translate" additive="sum" ... />
```

## freeze（保留最终状态）

控制动画结束后元素是否保持在最后一帧的状态。

可用元素：`animate`、`animateTransform`、`animateMotion`、`set` 均支持 `fill` 属性（`freeze`/`remove`）。

- **false**（默认，`isFreeze: false`）：动画结束后回到原始状态，适合循环或往返动效
- **true**（`isFreeze: true`）：动画结束后停留在最后一帧，适合一次性入场或状态切换

**与 loopCount 的关系**：

- 当 `loopCount: 0`（无限循环）时，动画不会结束，`isFreeze` 自然也不会生效
- 想定格需使用有限播放（通常 1 次）+ `isFreeze: true`

**本库取舍**：

- 入场/状态切换推荐：`loopCount: 1, isFreeze: true`
- 呼吸/闪烁/旋转等循环推荐：`loopCount: 0`（无需 `isFreeze`）

```typescript
// 一次性入场后保持
{transformScale({
  pivot: [187, 60],
  timeline: [{ durationSeconds: 0.6, toAbs: 1.2 }],
  isFreeze: true
})}
```

## native：覆盖/透传原生属性

每个动画函数都有 `native` 参数——传入原生 SMIL 元素的任意 JSX 属性，展开在函数生成的属性**之后**，同名属性直接覆盖生成值：

```typescript
import { transformScale } from '@guohub8080/expub-tool/smil'

// 例：补 id 供脚本 beginElement 触发
{transformScale({
  pivot: [187, 60],
  timeline: [{ toAbs: 2, durationSeconds: 1 }],
  native: { id: 'myScaleAnim' },
})}
// <animateTransform id="myScaleAnim" ... />
```

- 类型即原生元素属性：`T_NativeAnimate`（animate）、`T_NativeAnimateTransform`（animateTransform）、`T_NativeAnimateMotion`（animateMotion）
- 典型用途：补 `id`、`restart` 之外的辅助属性、微信特殊属性
- ⚠️ 不要用它覆盖 `values` / `keyTimes` / `dur` / `calcMode` 等由 timeline 编译出的属性——会破坏编译结果与 timeline 的一致性；这些请通过 config 字段（`timeline`/`calcMode`/`loopCount`…）控制

## 动画如何重新开始播放

常见的三种重播方式：

1. **React 重新挂载**：给包含动画的节点设置随参数变化的 `key`，变更时强制重新渲染，动画从头开始
2. **事件触发**：设置 `begin: 'click'`，点击后播放/重播
3. **脚本触发**：给动画元素设置 `id` 并在脚本中调用 `document.getElementById(id).beginElement()`

```typescript
// 方式1：React key 变更
<g key={[dur, easing, loopCount].join('-')}>
  {transformTranslate({...})}
</g>

// 方式2：点击触发
{transformScale({ pivot: [187, 60], timeline: [...], begin: 'click' })}

// 方式3：脚本触发（需要 id）
<animateTransform id="scaleAnim" begin="indefinite" ... />
// 脚本：document.getElementById('scaleAnim')?.beginElement();
```

## begin 字符串：事件 + 延迟的统一写法

新 API 不再有「事件类型 + 延迟」两个独立参数，统一写 `begin` 字符串（直接透传给 SMIL 的 `begin` 属性）：

| 需求 | begin 写法 | 说明 |
|------|-----------|------|
| 立即播放 | 不传（或 `begin: '0s'`） | 默认行为 |
| 延迟 N 秒自动开始 | `begin: '2s'` | 延迟自动开始 |
| 点击后播放 | `begin: 'click'` | 事件型 |
| 点击后延迟 N 秒 | `begin: 'click+0.5s'` | 事件 + 偏移 |

```typescript
// 延迟 2s 自动开始
{animateOpacity({ timeline: [{ durationSeconds: 0.6, toAbs: 1 }], begin: '2s' })}

// 点击后延迟 0.5s 播放
{transformRotate({ pivot: [187, 60], timeline: [{ durationSeconds: 3, toAbs: 360 }], begin: 'click+0.5s' })}
```

## 微信公众号编辑器环境（不支持 id）

在部分平台（如公众号编辑器）中无法使用 `id` 和脚本重播，推荐以下两种方式：

- **变更 key 重新挂载**：通过 React 的 `key` 强制重新渲染，动画从头开始；无需 `id` 或脚本权限
- **点击触发**：使用 `begin: 'click'`，用户点击目标元素即可播放/重播

```typescript
// 无 id 环境：推荐 1）变更 key 重播
<g key={[dur, easing, loopCount, version].join('-')}>
  {transformScale({ pivot: [187, 60], timeline: [...], loopCount: 1, isFreeze: true })}
</g>
// 变更 version 触发重播

// 或 2）点击触发（无需 id）
{transformScale({ pivot: [187, 60], timeline: [...], begin: 'click', loopCount: 1 })}
```

## 推荐设置（各动画函数）

### transformTranslate

- 循环动效：`loopCount: 0`；过渡动效：`loopCount: 1`
- 与其他变换组合：`isAdditive` 默认开启，调用方一般不必显式设置
- 需要停在终点：`isFreeze: true`

### transformScale

- **`pivot: [x, y]` 必填**：显式指定缩放支点（通常写元素中心坐标），无需任何 CSS 辅助
- 呼吸/脉动：`loopCount: 0`；一次性放大入场：`isFreeze: true`
- 初值用 `initValue`（默认 1），目标值用 `toAbs`

### transformRotate

- 围绕任意点旋转：传 `pivot: [x, y]`（缺省绕原点）；多支点路径式旋转用 `pivots` 数组
- 无缝旋转（转圈）：通常 `loopCount: 0` + 线性缓动
- 初值用 `initValue`（度数），目标用 `toAbs`（绝对角度）/ `toRel`（相对角度）

### animateOpacity

- 淡入后保持：`isFreeze: true`
- 循环闪烁：`loopCount: 0`
- 值域 0~1，初值 `initValue`（默认 1），目标 `toAbs`

## 常见模板示例

### 呼吸缩放

```typescript
{transformScale({
  initValue: 1,
  pivot: [187, 60],
  timeline: [
    { durationSeconds: 1.2, toAbs: 1.15, keySplines: getEaseBezier({ isIn: true, isOut: true }) },
    { durationSeconds: 1.2, toAbs: 1 }
  ],
  loopCount: 0
})}
```

### 一次性放大入场

```typescript
{transformScale({
  initValue: 0,
  pivot: [187, 60],
  timeline: [
    { durationSeconds: 0.6, toAbs: 1, keySplines: getEaseBezier({ isIn: true, isOut: true }) }
  ],
  loopCount: 1,
  isFreeze: true
})}
```

### 持续旋转

```typescript
{transformRotate({
  pivot: [100, 100],
  timeline: [
    { durationSeconds: 3, toAbs: 360, keySplines: getLinearBezier() }
  ],
  loopCount: 0
})}
```
