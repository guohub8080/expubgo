export const title = "KeySplines 生成函数"

# {title}

`buildTimeline`（时间轴编译器）是 SVG 动画系统的**底层参数计算工具**，从 `@guohub8080/expub-tool/smil` 导入。它只负责计算数字，不生成任何 SVG 代码。

## 核心概念

SVG 的 `<animate>` 和 `<animateTransform>` 标签需要三个核心参数：

- **keyTimes** - 关键时间点（如 `"0;0.5;1"`）
- **keySplines** - 缓动曲线（如 `"0.42 0 0.58 1"`）
- **values** - 关键值序列（如 `"0;100;0"`）

手动计算这些参数非常复杂，`buildTimeline` 可以自动完成！

## buildTimeline vs smil 动画函数

这两层工具经常被混淆，但它们处于**完全不同的层次**：

### 层次对比

```
┌─────────────────────────────────────────────────┐
│           用户看到的效果（圆形从左移到右）          │
└─────────────────────────────────────────────────┘
                        ↑
┌─────────────────────────────────────────────────┐
│  @guohub8080/expub-tool/smil 动画函数（高层）     │
│  ├── transformTranslate  (位移)                  │
│  ├── transformRotate     (旋转)                  │
│  ├── transformScale      (缩放)                  │
│  └── animateOpacity      (透明度)                │
│                                                 │
│  输出: 完整的 <animateTransform> 元素            │
│  用户可以直接放入 SVG 使用                       │
└─────────────────────────────────────────────────┘
                        ↑ 调用
┌─────────────────────────────────────────────────┐
│  buildTimeline (底层时间轴编译器)                 │
│                                                 │
│  输出: { keyTimes, keySplines, values,          │
│         totalDuration }                          │
│  只是纯数据，不涉及任何 SVG 结构                │
└─────────────────────────────────────────────────┘
```

### 核心区别

| 特性 | buildTimeline | smil 动画函数 |
|------|---------------|---------------|
| **层次** | 底层计算工具 | 高层动画生成器 |
| **输出** | 参数对象（纯数据） | React 元素（可渲染） |
| **职责** | 只计算时间/曲线/值 | 处理完整的动画逻辑 |
| **使用场景** | 需要完全自定义控制 | 快速生成常见动画 |
| **依赖关系** | 独立存在 | 内部调用 buildTimeline |

## 代码对比

### 场景：让一个圆形从左边移到右边（2秒，ease-in-out）

#### 方式 1：使用 buildTimeline（底层方式）

你需要自己处理所有细节：

```tsx
import { buildTimeline } from '@guohub8080/expub-tool/smil';

const MovingCircle = () => {
  // 第1步：计算参数
  const keys = buildTimeline({
    initValue: 0,
    timeline: [
      { keySplines: '0.42 0 0.58 1', toAbs: 200, durationSeconds: 2 }
    ]
  });
  // 结果: { keyTimes: '0;1', keySplines: '0.42 0 0.58 1', values: '0;200', totalDuration: 2 }

  // 第2步：手动组装 animateTransform 元素
  return (
    <svg width="300" height="100">
      <circle cx="50" cy="50" r="20" fill="blue">
        <animateTransform
          attributeName="transform"
          type="translate"
          values={keys.values}
          keyTimes={keys.keyTimes}
          keySplines={keys.keySplines}
          dur={`${keys.totalDuration}s`}
          calcMode="spline"
        />
      </circle>
    </svg>
  );
};
```

**优点**：完全控制每个属性
**缺点**：代码繁琐，容易出错

---

#### 方式 2：使用 smil 动画函数（高层方式）

只需要声明你的意图：

```tsx
import { transformTranslate } from '@guohub8080/expub-tool/smil';

const MovingCircle = () => {
  return (
    <svg width="300" height="100">
      <circle cx="50" cy="50" r="20" fill="blue">
        {/* 直接放入生成的元素 */}
        {transformTranslate({
          initValue: { x: 0, y: 0 },
          timeline: [
            { keySplines: '0.42 0 0.58 1', toAbs: { x: 200, y: 0 }, durationSeconds: 2 }
          ]
        })}
      </circle>
    </svg>
  );
};
```

**优点**：简洁、不易出错
**缺点**：灵活性较低（但通常足够用）

### transformTranslate 的内部实现

让我们看看 `transformTranslate` 内部是如何使用 `buildTimeline` 的：

```tsx
// 这是 transformTranslate 的简化实现逻辑（@guohub8080/expub-tool/smil）
function transformTranslate(config) {
  const { initValue, timeline } = config;

  // 1. 先把 toAbs / toRel 段展开为绝对坐标序列
  //    （toRel 是相对偏移，会累加到上一帧；toAbs 直接取目标值）
  const coordinates = buildCoordinates(initX, initY, timeline);

  // 2. 组装完整关键帧（缺省的 keySplines 补线性 "0 0 1 1"）
  const fullKeyframes = timeline.map((seg, i) => ({
    durationSeconds: seg.durationSeconds,
    toAbs: coordinates[i + 1],
    keySplines: defaultTo(seg.keySplines, LINEAR_KEY_SPLINE)
  }));

  // 3. 调用 buildTimeline 编译（serializer 把 {x, y} 序列化为 "x y"）
  const result = buildTimeline({
    initValue: { x: initX, y: initY },
    timeline: fullKeyframes,
    serializer: (v) => `${v.x} ${v.y}`
  });

  // 4. 返回完整的 animateTransform 元素
  return (
    <animateTransform
      attributeName="transform"
      type="translate"
      values={result.values}
      keyTimes={result.keyTimes}
      keySplines={result.keySplines}
      dur={`${result.totalDuration}s`}
      calcMode="spline"
    />
  );
}
```

**关键点**：`transformTranslate` 先用 `buildCoordinates` 把 `toRel` 相对位移累加成绝对坐标，再交给 `buildTimeline` 编译；复杂类型的值通过 `serializer` 自定义序列化。

## 什么时候用哪个？

### 使用 buildTimeline，当你需要：

1. **完全自定义动画属性**
   ```tsx
   // 想要一个特殊的动画效果
   <animate
     attributeName="stroke-dasharray"
     values={keys.values}
     keyTimes={keys.keyTimes}
     keySplines={keys.keySplines}
     calcMode="spline"
   />
   ```

2. **理解 SVG 动画的工作原理**
   - 学习 keyTimes/keySplines/values 的关系
   - 调试复杂的动画问题

3. **构建自己的动画生成工具**
   - 类似 smil 动画函数的自定义工具
   - 特定领域的动画生成器

4. **处理非标准的动画需求**
   - 多属性联动动画
   - 条件性动画控制

---

### 使用 smil 动画函数，当你需要：

1. **快速生成常见动画**
   ```tsx
   // 位移
   transformTranslate({ ... })
   // 旋转
   transformRotate({ ... })
   // 缩放
   transformScale({ ... })
   // 透明度
   animateOpacity({ ... })
   ```

2. **不想处理底层细节**
   - 不需要关心 keyTimes 如何计算
   - 不需要手动拼接 values 字符串

3. **直接可用的 SVG 元素**
   ```tsx
   <circle>
     {transformTranslate({ ... })}  {/* 直接放入即可 */}
   </circle>
   ```

4. **提高开发效率**
   - 行为类函数（`@guohub8080/expub-tool/behaviors`：软/硬闪烁、呼吸、漂浮等）
   - 属性类函数（animateX/animateY/animateR/animateMotion 等）

## 函数签名

### 输入参数

| 参数 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `initValue` | `T`（必填） | 动画的初始值，values 的第一个点 | `0`, `"0px"` |
| `timeline` | `I_TimelineKeyframe<T>[]` | 时间线段数组（至少 1 段） | 见下方表 |
| `serializer` | `(v: T) => string` | 值序列化函数，默认 `String`；translate 等复杂类型需自定义 | `(v) => \`${v.x} ${v.y}\`` |

**I_TimelineKeyframe 结构：**

| 参数 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `toAbs` | `T`（必填） | 该段的绝对目标值 | `100`, `{ x: 100, y: 0 }` |
| `durationSeconds` | `number`（必填） | 该段的持续时间（秒） | `2`, `1.5` |
| `keySplines` | `string`（可选） | 贝塞尔曲线参数，缺省为线性 `"0 0 1 1"` | `"0.42 0 0.58 1"` |

> 注：高层函数（`transformTranslate` / `transformRotate`）的时间线段用的是 `toAbs` / `toRel` 二选一（相对偏移），`buildTimeline` 本身只接受 `toAbs`。

### 输出结果

| 参数 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `keyTimes` | `string` | 关键时间点（分号分隔） | `"0;0.4;1"` |
| `keySplines` | `string` | 缓动曲线参数（分号分隔） | `"0.42 0 0.58 1;0 0 0.58 1"` |
| `values` | `string` | 关键值序列（分号分隔） | `"0;100;200"` |
| `totalDuration` | `number` | 动画总时长（秒） | `5` |

## 参数计算原理

### keyTimes 计算方式

```
相对时间 = 累计时间 / 总时长

例如：
总时长 = 5秒

第1段：2秒 → 2/5 = 0.4
第2段：3秒 → (2+3)/5 = 1.0

keyTimes = "0;0.4;1"
```

### values 构建方式

```
values = [初始值, 目标值1, 目标值2, ...]

例如：
initValue = 0
第1段 toAbs = 100
第2段 toAbs = 200

values = "0;100;200"
```

### keySplines 拼接方式

```
keySplines = [第1段, 第2段, ...]

注意：keySplines 的数量 = keyTimes 数量 - 1
某段未填 keySplines 时自动补线性 "0 0 1 1"
```

## 错误处理

### timeline 为空

```typescript
// ❌ 错误
buildTimeline({
  initValue: 0,
  timeline: []
})
// Error: `timeline` must not be empty.
```

### initValue 缺失

```typescript
// ❌ 错误
buildTimeline({
  initValue: undefined,
  timeline: [{ toAbs: 100, durationSeconds: 2 }]
})
// Error: `initValue` must not be null or undefined,
//        SMIL requires values/keyTimes count to match.
```

`initValue` 是 values 的第一个点，SMIL 要求 values 与 keyTimes 点数相等（timeline.length + 1），因此它必须显式提供。

### 总时长为 0

```typescript
// ❌ 错误
buildTimeline({
  initValue: 0,
  timeline: [
    { keySplines: '0 0 1 1', toAbs: 100, durationSeconds: 0 }
  ]
})
// Error: `totalDuration` must be greater than 0.
```

> 注：`buildTimeline` 不校验 keySplines 的格式——写错格式的曲线不会被拦截，只在渲染时表现为异常缓动，请自行确保 `"x1 y1 x2 y2"` 四段数字格式（或直接用包内 `getEaseBezier` 等函数生成）。

## 配合其他工具使用

### 与缓动函数配合

```tsx
import { buildTimeline, getEaseBezier, getPowerBezier } from '@guohub8080/expub-tool/smil';

const keys = buildTimeline({
  initValue: 0,
  timeline: [
    {
      keySplines: getEaseBezier({ isIn: true, isOut: true }),
      toAbs: 100,
      durationSeconds: 2
    },
    {
      keySplines: getPowerBezier({ power: 4, isIn: false, isOut: true }),
      toAbs: 200,
      durationSeconds: 3
    }
  ]
});
```
