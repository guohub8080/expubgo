多角度旋转可以创建复杂的旋转路径，元素依次旋转到多个指定角度。

---

## 卫星往返轨道

元素在轨道上来回摆动，展示多角度序列动画。

**代码示例：**

```tsx
transformRotate({
  initValue: 0,
  pivot: [100, 100],        // 轨道中心
  timeline: [
    { toAbs: 120, durationSeconds: 1 },      // 向右下
    { toAbs: -120, durationSeconds: 2 },     // 摆动到左侧
    { toAbs: 120, durationSeconds: 2 },      // 摆动到右侧
    { toAbs: -120, durationSeconds: 2 },     // 摆动到左侧
    { toAbs: 0, durationSeconds: 1 }         // 回到原位
  ],
  loopCount: 0
})
```

## 多角度序列配方

多角度序列直接把各目标角度写成多段 `toAbs`（时长均分即可）：

```tsx
// 角度数组 [90, 180, 270, 360]，总时长 4 秒（每段 1 秒）
transformRotate({
  timeline: [
    { toAbs: 90, durationSeconds: 1 },
    { toAbs: 180, durationSeconds: 1 },
    { toAbs: 270, durationSeconds: 1 },
    { toAbs: 360, durationSeconds: 1 }
  ]
})
```

若各段需要绕**不同的中心**旋转，用 `pivots` 逐帧给出支点（长度 = timeline.length + 1）：

```tsx
transformRotate({
  timeline: [
    { toAbs: 90, durationSeconds: 1 },
    { toAbs: 180, durationSeconds: 1 },
    { toAbs: 270, durationSeconds: 1 }
  ],
  pivots: [
    [100, 100],   // initValue 帧
    [100, 100],   // 第 1 段支点
    [150, 150],   // 第 2 段换支点
    [100, 100]    // 第 3 段支点
  ]
})
```

## 复杂路径示例

### 阶梯式旋转

```tsx
// [45, 90, 135…360] 逐级上升，总时长 6 秒（每段 0.75 秒）
transformRotate({
  timeline: [
    { toAbs: 45, durationSeconds: 0.75 },
    { toAbs: 90, durationSeconds: 0.75 },
    { toAbs: 135, durationSeconds: 0.75 },
    { toAbs: 180, durationSeconds: 0.75 },
    { toAbs: 225, durationSeconds: 0.75 },
    { toAbs: 270, durationSeconds: 0.75 },
    { toAbs: 315, durationSeconds: 0.75 },
    { toAbs: 360, durationSeconds: 0.75 }
  ]
})
```

### 往返多段

```tsx
transformRotate({
  initValue: 0,
  timeline: [
    { toAbs: 120, durationSeconds: 1 },
    { toAbs: -60, durationSeconds: 1.5 },
    { toAbs: 60, durationSeconds: 1 },
    { toAbs: 0, durationSeconds: 1 }
  ]
})
```

### 停顿效果

```tsx
transformRotate({
  initValue: 0,
  timeline: [
    { toAbs: 90, durationSeconds: 1 },
    { toAbs: 90, durationSeconds: 0.5 },  // 停顿
    { toAbs: 180, durationSeconds: 1 },
    { toAbs: 180, durationSeconds: 0.5 }, // 停顿
    { toAbs: 270, durationSeconds: 1 }
  ]
})
```

## 应用场景

### 指针旋转

```tsx
// [30, 60, 90, 120, 150, 180]，总时长 3 秒（每段 0.5 秒）
transformRotate({
  pivot: [100, 100],
  timeline: [
    { toAbs: 30, durationSeconds: 0.5 },
    { toAbs: 60, durationSeconds: 0.5 },
    { toAbs: 90, durationSeconds: 0.5 },
    { toAbs: 120, durationSeconds: 0.5 },
    { toAbs: 150, durationSeconds: 0.5 },
    { toAbs: 180, durationSeconds: 0.5 }
  ]
})
```

### 多段动画

```tsx
transformRotate({
  initValue: 0,
  timeline: [
    { toAbs: 45, durationSeconds: 0.5 },
    { toAbs: -45, durationSeconds: 1 },
    { toAbs: 0, durationSeconds: 0.5 }
  ],
  isFreeze: true
})
```
