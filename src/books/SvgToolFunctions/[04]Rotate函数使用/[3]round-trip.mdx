# {title}

往返旋转让元素在两个角度之间来回切换，创造循环动画效果。

---

## 连续旋转

元素持续向一个方向旋转，无限循环。

**代码示例：**

```tsx
transformRotate({
  pivot: [100, 100],
  timeline: [
    { toAbs: 360, durationSeconds: 1 }
  ],
  loopCount: 0  // 无限循环
})
```

**效果预览：**

<ContinuousRotate />

**说明**：使用 `loopCount: 0` 实现无限循环旋转

---

## 摇摆旋转

元素在两个角度之间左右摇摆。

**代码示例：**

```tsx
transformRotate({
  pivot: [100, 100],
  initValue: -30,
  timeline: [
    { toAbs: 30, durationSeconds: 0.8 },
    { toAbs: -30, durationSeconds: 0.8 }
  ],
  loopCount: 0
})
```

**效果预览：**

<SwingRotate />

**说明**：从 -30° 摇摆到 30°，然后返回，形成钟摆效果

---

## 摇摆配方

左右摇摆直接用「对称双段 timeline」表达：

```tsx
// 摇摆幅度 30°，完整周期 2 秒（单程 1 秒）
transformRotate({
  initValue: -30,
  timeline: [
    { toAbs: 30, durationSeconds: 1, keySplines: '0.45 0 0.55 1' },
    { toAbs: -30, durationSeconds: 1, keySplines: '0.45 0 0.55 1' }
  ],
  loopCount: 0
})
```

这等同于上面的手动配置，只是补充了缓动曲线。

## 应用场景

### 加载动画

```tsx
transformRotate({
  timeline: [
    { toAbs: 360, durationSeconds: 0.8 }
  ],
  loopCount: 0
})
```

### 提示动画

```tsx
// 小幅度摇摆：±15°，完整周期 1 秒
transformRotate({
  initValue: -15,
  timeline: [
    { toAbs: 15, durationSeconds: 0.5, keySplines: '0.45 0 0.55 1' },
    { toAbs: -15, durationSeconds: 0.5, keySplines: '0.45 0 0.55 1' }
  ],
  loopCount: 0
})
```

### 呼吸效果

```tsx
transformRotate({
  initValue: -10,
  timeline: [
    { toAbs: 10, durationSeconds: 1 },
    { toAbs: -10, durationSeconds: 1 }
  ],
  loopCount: 0
})
```
