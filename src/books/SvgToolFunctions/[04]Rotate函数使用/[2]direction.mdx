export const title = "旋转方向"

import { ClockwiseRotate, CounterClockwiseRotate, HalfRotate } from "./examples"

# {title}

旋转方向由角度的正负决定：正值顺时针，负值逆时针。

---

## 顺时针旋转

正值角度表示顺时针方向旋转。

**代码示例：**

```tsx
<svg width="200" height="200" viewBox="0 0 200 200">
  <circle cx="100" cy="100" r="30" fill="blue">
    {transformRotate({
      timeline: [
        { toAbs: 360, durationSeconds: 2 }
      ]
    })}
  </circle>
</svg>
```

**效果预览：**

<ClockwiseRotate />

**说明**：未指定 `pivot` 时围绕坐标原点 (0, 0) 旋转，蓝色圆形顺时针公转 360°（完整一圈）

---

## 逆时针旋转

负值角度表示逆时针方向旋转。

**代码示例：**

```tsx
<svg width="200" height="200" viewBox="0 0 200 200">
  <circle cx="100" cy="100" r="30" fill="green">
    {transformRotate({
      timeline: [
        { toAbs: -360, durationSeconds: 2 }
      ]
    })}
  </circle>
</svg>
```

**效果预览：**

<CounterClockwiseRotate />

**说明**：绿色圆形绕坐标原点 (0, 0) 逆时针公转 360°

---

## 半圈旋转

旋转 180°（半圈）常用于翻转效果。

**代码示例：**

```tsx
<svg width="200" height="200" viewBox="0 0 200 200">
  <rect x="75" y="75" width="50" height="50" fill="orange">
    {transformRotate({
      pivot: [100, 100],
      timeline: [
        { toAbs: 180, durationSeconds: 1 }
      ],
      isFreeze: true
    })}
  </rect>
</svg>
```

**效果预览：**

<HalfRotate />

**说明**：橙色方块围绕自身中心旋转 180° 后保持最终位置

---

## 角度参考

| 角度 | 说明 | 效果 |
|------|------|------|
| `360` | 顺时针一圈 | 完整旋转 |
| `-360` | 逆时针一圈 | 完整旋转 |
| `180` | 顺时针半圈 | 翻转 |
| `-180` | 逆时针半圈 | 翻转 |
| `90` | 顺时针直角 | 1/4 圈 |
| `-90` | 逆时针直角 | 1/4 圈 |
