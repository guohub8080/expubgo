# {title}

timeline 每一段的目标角度用 `toRel`（相对）或 `toAbs`（绝对）指定，两种写法表达不同的角度语义。理解它们的区别对于创建复杂的旋转动画至关重要。

---

## 相对旋转（toRel）

每段的 `toRel` 是**相对于上一阶段终点**的增量角度。

### 工作原理

```
当前角度 = 上一阶段角度 + toRel
```

**示例：**

```tsx
transformRotate({
  initValue: 0,
  pivot: [100, 100],
  timeline: [
    { toRel: 90, durationSeconds: 1 },    // 0 + 90 = 90°
    { toRel: 0, durationSeconds: 1 },     // 90 + 0 = 90°（保持）
    { toRel: 90, durationSeconds: 1 }     // 90 + 90 = 180°
  ]
})
```

### 效果预览

<RelativeMode />

**说明**：0° → 90° → 保持不动 → 再转 90° 到 180°

---

## 绝对旋转（toAbs）

每段的 `toAbs` 是**相对于初始角度**的绝对角度。

### 工作原理

```
当前角度 = toAbs（绝对角度）
```

**示例：**

```tsx
transformRotate({
  initValue: 0,
  pivot: [100, 100],
  timeline: [
    { toAbs: 90, durationSeconds: 1 },    // 旋转到 90°
    { toAbs: 90, durationSeconds: 1 },    // 保持在 90°
    { toAbs: 180, durationSeconds: 1 }    // 旋转到 180°
  ]
})
```

### 效果预览

<AbsoluteMode />

**说明**：0° → 90° → 保持 90° → 180°

## 两种模式对比

虽然两个示例最终效果相同，但参数写法不同：

| 阶段 | 相对 `toRel` | 实际角度 | 绝对 `toAbs` |
|------|-------------|---------|-------------|
| 初始 | - | 0° | - |
| 第1段 | `90` | 0° + 90° = **90°** | `90` → **90°** |
| 第2段 | `0` | 90° + 0° = **90°** | `90` → **90°** |
| 第3段 | `90` | 90° + 90° = **180°** | `180` → **180°** |

## 关键区别

### 相对写法（推荐）

```tsx
// ✅ 保持不动很简单
{ toRel: 0 }  // 相对于上一阶段，增量是 0
```

### 绝对写法

```tsx
// ❌ 保持不动需要重复上一个角度
{ toAbs: 90 }  // 必须写绝对角度 90
```

---

## 使用场景

### 场景 1：单次旋转

两种写法都可以：

```tsx
transformRotate({
  timeline: [
    { toAbs: 360, durationSeconds: 2 }
  ]
})
```

### 场景 2：往返摆动

相对写法更直观：

```tsx
transformRotate({
  initValue: -30,
  pivot: [100, 100],
  timeline: [
    { toRel: 60, durationSeconds: 1 },    // -30 + 60 = 30°
    { toRel: -60, durationSeconds: 1 }    // 30 + (-60) = -30°
  ],
  loopCount: 0
})
```

### 场景 3：复杂路径

相对写法更容易理解增量：

```tsx
transformRotate({
  initValue: 0,
  timeline: [
    { toRel: 45, durationSeconds: 1 },    // 向右转 45°
    { toRel: 0, durationSeconds: 1 },     // 返回 45°
    { toRel: -45, durationSeconds: 1 },   // 向左转 45°
    { toRel: 0, durationSeconds: 1 }      // 返回中心
  ]
})
```

---

## 总结

| 特性 | 相对写法 | 绝对写法 |
|------|---------|---------|
| **字段** | `toRel: 90` | `toAbs: 90` |
| **含义** | 增量角度 | 绝对角度 |
| **保持不动** | `{ toRel: 0 }` | 需重复上一角度 |
| **适用场景** | 大多数情况 | 需要精确控制绝对角度 |

**推荐**：增量思维时用 `toRel`，更符合直觉；目标角度明确时用 `toAbs`，直接了当。
