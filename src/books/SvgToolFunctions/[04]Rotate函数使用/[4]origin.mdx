import { CenterOrigin, CornerOrigin, CustomOrigin } from "./examples"

# {title}

`pivot` 参数控制旋转中心点（轴心）。

**重要**：默认情况下（不提供 `pivot`），元素围绕 SVG 坐标原点 (0, 0) 旋转，而不是元素中心！要实现元素中心旋转，需要显式提供 `pivot: [cx, cy]` 坐标。

---

## 默认原点旋转

不指定 `pivot` 时，元素围绕 SVG 坐标原点 (0, 0) 旋转。

**代码示例：**

```tsx
<svg width="200" height="200" viewBox="0 0 200 200">
  <rect x="75" y="75" width="50" height="50" fill="blue">
    {transformRotate({
      timeline: [
        { toAbs: 360, durationSeconds: 2 }
      ]
    })}
  </rect>
</svg>
```

**效果预览：**

<CenterOrigin />

**说明**：方块围绕 SVG 坐标原点 (0, 0) 旋转（红色标记点为原点）

---

## 角落旋转

将旋转中心点设置为元素的一个角。

**代码示例：**

```tsx
<svg width="200" height="200" viewBox="0 0 200 200">
  <g>
    {transformRotate({
      timeline: [
        { toAbs: 360, durationSeconds: 2 }
      ],
      loopCount: 0,
      pivot: [75, 75]  // 左上角坐标
    })}
    <rect x="75" y="75" width="50" height="50" fill="green" />
  </g>
</svg>
```

**效果预览：**

<CornerOrigin />

**说明**：方块围绕左上角 (75, 75) 旋转

---

## 自定义中心点

可以指定任意的旋转中心点。

**代码示例：**

```tsx
<svg width="200" height="200" viewBox="0 0 200 200">
  <g>
    {transformRotate({
      timeline: [
        { toAbs: 360, durationSeconds: 2 }
      ],
      loopCount: 0,
      pivot: [100, 150]  // 自定义坐标
    })}
    <rect x="75" y="75" width="50" height="50" fill="orange" />
  </g>
</svg>
```

**效果预览：**

<CustomOrigin />

**说明**：方块围绕外部点 (100, 150) 旋转，形成轨道效果

---

## pivot 参数格式

```tsx
// 常量支点：自定义坐标 [x, y]
pivot: [100, 100]     // 坐标 (100, 100)
pivot: [75, 75]        // 坐标 (75, 75)

// 逐帧支点：每关键帧一个坐标（长度 = timeline.length + 1，initValue 帧在前）
// 适合「一个元素跨多段、每段绕不同中心」的场景
pivots: [[100, 100], [100, 100], [150, 150]]
```

---

## 使用技巧

### 1. 卫星效果

元素围绕外部点旋转，模拟卫星轨道。

```tsx
pivot: [150, 100]  // 远离元素的点
```

### 2. 围绕元素中心旋转

直接写元素中心坐标（按元素位置计算）。

```tsx
// 元素位于 (75, 75)，尺寸 50×50，中心即 (100, 100)
transformRotate({
  pivot: [100, 100]
})
```
