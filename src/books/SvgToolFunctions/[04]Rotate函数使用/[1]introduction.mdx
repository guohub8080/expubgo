# {title}

`transformRotate` 是 SVG 旋转动画的核心函数（来自 `@guohub8080/expub-tool/smil`），可以让元素围绕指定点进行旋转运动。

---

## 函数签名

```tsx
import { transformRotate } from "@guohub8080/expub-tool/smil";

transformRotate({
  // ===== 必填参数 =====
  timeline: RotateTimelineSegment[],   // 必填：时间线段数组（每段 toAbs / toRel 二选一）

  // ===== 可选参数 =====
  initValue?: number,                  // 初始角度（度），默认 0
  pivot?: [number, number],            // 旋转中心 [x, y]，默认 [0, 0]（SVG 坐标原点）
  pivots?: [number, number][],         // 逐关键帧旋转中心（长度 = timeline.length + 1）
  begin?: string,                      // 开始时机：'2s'（延迟）/ 'click' / 'click+0.5s'
  isAdditive?: boolean,                // 是否累加变换，默认 true
  calcMode?: 'spline' | 'linear' | 'discrete' | 'paced',  // 动画计算模式，自动
  isFreeze?: boolean,                  // 是否保持最终状态，默认 false
  loopCount?: number,                  // 循环次数（0 = 无限），默认 1
  native?: T_NativeAnimateTransform,   // 透传/覆盖原生 animateTransform 属性（最后展开，同名覆盖生成值）
})
```

---

## 核心参数

创建一个 360° 顺时针旋转的方块。

**代码示例：**

```tsx
import { transformRotate } from "@guohub8080/expub-tool/smil";

<svg width="200" height="200" viewBox="0 0 200 200">
  <rect x="75" y="75" width="50" height="50" fill="blue">
    {transformRotate({
      pivot: [100, 100],   // 方块中心，绕自身中心旋转
      timeline: [
        { toAbs: 360, durationSeconds: 2 }
      ],
      loopCount: 0
    })}
  </rect>
</svg>
```

**说明**：蓝色方块围绕中心点 (100, 100) 顺时针无限旋转

## 核心参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `timeline` | `RotateTimelineSegment[]` | **必填** | 动画时间线配置 |
| `timeline[].toAbs` | `number` | - | 目标绝对角度（度） |
| `timeline[].toRel` | `number` | - | 相对上一阶段的增量角度（度） |
| `timeline[].durationSeconds` | `number` | - | 该阶段时长（秒） |
| `initValue` | `number` | `0` | 初始角度 |
| `pivot` | `[number, number]` | `[0, 0]` | 旋转中心点坐标 |

---

## 旋转方向

**正值** = 顺时针旋转
**负值** = 逆时针旋转

```tsx
// 顺时针 360°
{ toAbs: 360, durationSeconds: 2 }

// 逆时针 360°
{ toAbs: -360, durationSeconds: 2 }

// 顺时针 180°
{ toAbs: 180, durationSeconds: 1 }
```

## 常见使用场景

### 1. 加载动画

无限旋转的圆形或箭头。

```tsx
transformRotate({
  timeline: [
    { toAbs: 360, durationSeconds: 1 }
  ],
  loopCount: 0  // 无限循环
})
```

### 2. 摇摆效果

左右摇摆的元素。

```tsx
transformRotate({
  initValue: -20,
  timeline: [
    { toAbs: 20, durationSeconds: 0.5 },
    { toAbs: -20, durationSeconds: 0.5 }
  ],
  loopCount: 0
})
```

### 3. 翻转效果

180° 翻转动画。

```tsx
transformRotate({
  timeline: [
    { toAbs: 180, durationSeconds: 0.8 }
  ],
  isFreeze: true
})
```

## 常用配方

新 API 只有一个 `transformRotate`，常见场景直接用 timeline 多段表达：

| 场景 | 配方 |
|------|------|
| 指定角度旋转 | `{ timeline: [{ toAbs: 360, durationSeconds: 2 }] }` |
| 往返旋转 | `initValue: 0` + 两段 `toAbs`（目标角度 → 回 0）+ `loopCount: 0` |
| 左右摇摆 | `initValue: -30` + 两段 `toAbs: 30 / -30` + `loopCount: 0` |
| 多角度序列 | 多段 `toAbs` 依次列出各目标角度 |

展开写法：

```tsx
// 往返旋转：0° ↔ 180°，单程 1.5 秒
transformRotate({
  timeline: [
    { toAbs: 180, durationSeconds: 1.5 },
    { toAbs: 0, durationSeconds: 1.5 }
  ],
  loopCount: 0
})

// 左右摇摆：-30° ↔ 30°，完整周期 2 秒
transformRotate({
  initValue: -30,
  timeline: [
    { toAbs: 30, durationSeconds: 1, keySplines: '0.45 0 0.55 1' },
    { toAbs: -30, durationSeconds: 1, keySplines: '0.45 0 0.55 1' }
  ],
  loopCount: 0
})

// 多角度序列：90° → 180° → 270° → 360°，总时长 4 秒
transformRotate({
  timeline: [
    { toAbs: 90, durationSeconds: 1 },
    { toAbs: 180, durationSeconds: 1 },
    { toAbs: 270, durationSeconds: 1 },
    { toAbs: 360, durationSeconds: 1 }
  ]
})
```
