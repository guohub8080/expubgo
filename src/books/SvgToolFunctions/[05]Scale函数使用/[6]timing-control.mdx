# {title}

缩放动画的时序控制是创建复杂动画效果的关键。本文介绍 `transformScale` 中与时序相关的三个核心参数：`begin`、`loopCount` 和 `isFreeze`。其中 `begin` 用一个字符串统一了"延迟自动开始"与"事件触发"两类开始时机。

---

## 核心参数

| 参数 | 默认值 | 说明 | 使用场景 |
|------|--------|------|----------|
| `begin` | `undefined`（立即开始） | 开始时机：`'2s'` 延迟自动开始；`'click'` 点击触发 | 序列动画、交互式动画 |
| `loopCount` | `1` | 循环次数（0 = 无限）| 呼吸效果、重复提示 |
| `isFreeze` | `false` | 保持最终状态 | 入场动画、状态切换 |

---

## begin - 开始时机

`begin` 是字符串，直接写延迟或事件：

| 写法 | 含义 |
|------|------|
| `begin: '2s'` | 页面加载 2 秒后自动开始 |
| `begin: 'click'` | 点击元素后才开始播放 |
| `begin: 'click+0.5s'` | 点击后延迟 0.5 秒开始 |

**类型**：`string`
**默认值**：`undefined`（立即开始）

### 延迟自动开始

```tsx
transformScale({
  pivot: [100, 80],
  initValue: 1,
  timeline: [
    { toAbs: 1.5, durationSeconds: 2 }
  ],
  begin: '1s'  // 延迟 1 秒后开始
})
```

**效果预览：**

<DelayDemo />

**说明**：方块延迟 1 秒后开始放大

### 点击触发

```tsx
transformScale({
  pivot: [100, 80],
  timeline: [
    { toAbs: 1.5, durationSeconds: 2 }
  ],
  begin: 'click',
  isFreeze: true  // 通常配合 isFreeze 使用
})
```

**效果预览：**

<ClickTriggerDemo />

**说明**：点击圆圈后才开始放大，动画结束后保持最终大小

**使用场景**：
- 序列动画（多个元素依次出现，用不同延迟值）
- 入场动画（页面加载后延迟播放）
- 交互式动画（用户点击触发、按需播放）

## loopCount - 循环次数

控制动画播放的次数。

**类型**：`number`
**默认值**：`1`
**特殊值**：`0` 表示无限循环

**使用场景**：
- 呼吸效果（无限循环）
- 重复提示（循环 2-3 次）
- 单次动画（默认值 1）

**示例：**

```tsx
// 播放 1 次（默认）
transformScale({
  pivot: [100, 100],
  timeline: [
    { toAbs: 1.5, durationSeconds: 2 }
  ],
  loopCount: 1
})

// 播放 3 次
transformScale({
  pivot: [100, 100],
  timeline: [
    { toAbs: 1.8, durationSeconds: 2 }
  ],
  loopCount: 3
})

// 无限循环
transformScale({
  pivot: [100, 100],
  timeline: [
    { toAbs: 1.2, durationSeconds: 1 },
    { toAbs: 0.8, durationSeconds: 1 }
  ],
  loopCount: 0
})
```

**效果预览：**

<LoopDemo />

**说明**：从左到右依次为：播放1次、播放3次、无限循环

## isFreeze - 保持最终状态

控制动画结束后是否停留在最后一帧。

**类型**：`boolean`
**默认值**：`false`

**值说明**：
- `false`（默认）：动画结束后回到初始状态
- `true`：动画结束后停留在最终位置

**使用场景**：
- 入场动画（元素放大后保持大小）
- 状态切换（从 A 状态变到 B 状态）
- 单次动画（不需要回到原位）

**示例：**

```tsx
// 动画结束后回到原位
transformScale({
  pivot: [100, 100],
  timeline: [
    { toAbs: 1.5, durationSeconds: 2 }
  ],
  isFreeze: false  // 默认值
})

// 动画结束后保持最终位置
transformScale({
  pivot: [100, 100],
  timeline: [
    { toAbs: 1.5, durationSeconds: 2 }
  ],
  isFreeze: true
})
```

**效果预览：**

<FreezeDemo />

**说明**：上方动画结束后回到原位，下方保持最终大小

## 参数组合

### 组合 1：延迟 + 循环

创建延迟开始的循环动画。

```tsx
transformScale({
  pivot: [100, 100],
  initValue: 1,
  timeline: [
    { toAbs: 1.2, durationSeconds: 1 },
    { toAbs: 0.8, durationSeconds: 1 }
  ],
  begin: '2s',    // 延迟 2 秒
  loopCount: 0    // 无限循环
})
```

**使用场景**：页面加载后延迟播放的呼吸效果。

---

### 组合 2：点击 + 冻结

创建点击触发的单次动画。

```tsx
transformScale({
  pivot: [100, 100],
  timeline: [
    { toAbs: 1.5, durationSeconds: 2 }
  ],
  begin: 'click',  // 点击触发
  isFreeze: true   // 保持最终位置
})
```

**使用场景**：点击按钮后元素放大到新位置并停留。

---

### 组合 3：点击 + 延迟 + 冻结

创建延迟触发的交互式动画。

```tsx
transformScale({
  pivot: [100, 100],
  timeline: [
    { toAbs: 1.5, durationSeconds: 2 }
  ],
  begin: 'click+1s',  // 点击后延迟 1 秒
  isFreeze: true      // 保持最终位置
})
```

**使用场景**：点击后延迟播放的入场动画。

---

### 组合 4：循环 + 冻结

创建循环指定次数后停留的动画。

```tsx
transformScale({
  pivot: [100, 100],
  timeline: [
    { toAbs: 1.8, durationSeconds: 1 },
    { toAbs: 0.2, durationSeconds: 1 }
  ],
  loopCount: 3,  // 循环 3 次
  isFreeze: true // 最后停留在最终位置
})
```

**使用场景**：提示动画（摆动 3 次后停止）。

---

## 使用场景

### 场景 1：入场动画

元素从小到大出现，并保持大小。

```tsx
transformScale({
  pivot: [100, 100],
  initValue: 0,
  timeline: [
    { toAbs: 1, durationSeconds: 1 }
  ],
  begin: '0.5s',  // 延迟 0.5 秒
  isFreeze: true  // 保持最终大小
})
```

### 场景 2：呼吸效果

元素持续放大缩小。

```tsx
transformScale({
  pivot: [100, 100],
  timeline: [
    { toAbs: 1.2, durationSeconds: 1 },
    { toAbs: 0.8, durationSeconds: 1 }
  ],
  loopCount: 0  // 无限循环
})
```

### 场景 3：交互式动画

点击元素后触发缩放。

```tsx
transformScale({
  pivot: [100, 100],
  timeline: [
    { toAbs: 1.5, durationSeconds: 1.5 }
  ],
  begin: 'click',
  isFreeze: true
})
```

---

## 总结

| 参数 | 默认值 | 说明 | 常用场景 |
|------|--------|------|----------|
| `begin` | `undefined` | 开始时机（`'2s'` / `'click'` / `'click+1s'`） | 序列动画、交互式动画 |
| `loopCount` | `1` | 循环次数（0 = 无限）| 呼吸效果、重复提示 |
| `isFreeze` | `false` | 保持最终状态 | 入场动画、状态切换 |

**推荐组合**：
- 入场动画：`begin: '0.5s'` + `isFreeze`
- 呼吸效果：`loopCount: 0`
- 交互式动画：`begin: 'click'` + `isFreeze`
- 序列动画：不同的 `begin` 延迟值
