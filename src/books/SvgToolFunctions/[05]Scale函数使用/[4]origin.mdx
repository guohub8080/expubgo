# {title}

`pivot` 参数控制缩放中心点（轴心），**必填**，格式为坐标数组 `[x, y]`。

**重要**：缩放严格围绕 `pivot` 指定的坐标进行。若把 `pivot` 写成 `[0, 0]`（SVG 坐标原点），元素会向右下方扩展；要让元素围绕自身中心缩放，需按元素几何位置算出中心坐标写入 `pivot`。

---

## 围绕 SVG 原点缩放

把 `pivot` 写成 `[0, 0]` 时，元素围绕 SVG 坐标原点缩放。

**代码示例：**

```tsx
<svg width="200" height="200" viewBox="0 0 200 200">
  <rect x="75" y="75" width="50" height="50" fill="blue">
    {transformScale({
      pivot: [0, 0],
      timeline: [
        { toAbs: 2, durationSeconds: 2 }
      ]
    })}
  </rect>
</svg>
```

**说明**：方块围绕左上角 (0, 0) 放大，会向右下方扩展

---

## 元素中心缩放

按元素几何位置算出中心坐标，直接写入 `pivot`。

**代码示例：**

```tsx
<svg width="200" height="200" viewBox="0 0 200 200">
  <rect x="75" y="75" width="50" height="50" fill="blue">
    {transformScale({
      pivot: [100, 100],   // 中心 = (75 + 50/2, 75 + 50/2)
      timeline: [
        { toAbs: 2, durationSeconds: 2 }
      ]
    })}
  </rect>
</svg>
```

**效果预览：**

<CenterOrigin />

**说明**：方块围绕自身中心 (100, 100) 放大，向四周均匀扩展

## pivot 参数格式

```tsx
// 坐标数组格式：[x, y]，必填
pivot: [100, 100]     // 元素中心坐标
pivot: [75, 75]        // 元素左上角坐标
pivot: [0, 0]          // SVG 坐标原点
```

---

## 使用技巧

### 1. 用元素几何算坐标

以矩形 `x=75, y=75, width=50, height=50` 为例：

| 目标支点 | 计算方式 | pivot |
|----------|----------|-------|
| 左上角 | `(x, y)` | `[75, 75]` |
| 中心 | `(x + w/2, y + h/2)` | `[100, 100]` |
| 右下角 | `(x + w, y + h)` | `[125, 125]` |

圆形 `cx=100, cy=80, r=25` 的中心就是 `pivot: [100, 80]`。

### 2. 直接写配方

```tsx
import { transformScale } from "@guohub8080/expub-tool/smil";

// 放大 2 倍（围绕元素中心）
transformScale({
  pivot: [100, 100],
  timeline: [{ toAbs: 2, durationSeconds: 2 }]
})

// 缩小到 0.5 倍
transformScale({
  pivot: [100, 100],
  timeline: [{ toAbs: 0.5, durationSeconds: 1.5 }]
})
```

### 3. 自定义缩放中心

```tsx
transformScale({
  pivot: [100, 100],  // 任意自定义坐标
  timeline: [
    { toAbs: 2, durationSeconds: 2 }
  ]
})
```
