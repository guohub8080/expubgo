# {title}

往返缩放会让元素在两个缩放比例之间来回切换，创造呼吸般的动画效果。

---

## 循环缩放

元素在两个缩放比例之间来回切换，无限循环。

**代码示例：**

```tsx
transformScale({
  initValue: 1,
  pivot: [100, 100],
  timeline: [
    { toAbs: 1.5, durationSeconds: 1 },
    { toAbs: 0.8, durationSeconds: 1 }
  ],
  loopCount: 0
})
```

**效果预览：**

<Loop />

**说明**：圆形在 0.8 倍和 1.5 倍之间无限循环

## 对比演示

两种不同方式的往返缩放并排展示。

**代码示例：**

```tsx

  initValue: 1,
  pivot: [100, 100],
  timeline: [
    { toAbs: 1.8, durationSeconds: 1.5 },
    { toAbs: 0.5, durationSeconds: 1.5 }
  ],
  loopCount: 0

// 摇摆缩放：小范围快速摇摆
transformScale({
  initValue: 1,
  pivot: [100, 100],
  timeline: [
    { toAbs: 1.2, durationSeconds: 0.5 },
    { toAbs: 0.8, durationSeconds: 0.5 }
  ],
  loopCount: 0
})
```

**效果预览：**

<Comparison />

**说明**：左侧大幅度往返，右侧小幅度摇摆

## 往返缩放配方

往返效果直接写成两段 timeline（目标值 + 回初值），配合无限循环：

```tsx
import { transformScale } from "@guohub8080/expub-tool/smil";

// 0.8 倍 ↔ 1.2 倍，单程 1.5 秒，无限往返
transformScale({
  pivot: [100, 100],
  initValue: 1.2,
  timeline: [
    { toAbs: 0.8, durationSeconds: 1.5 },
    { toAbs: 1.2, durationSeconds: 1.5 }
  ],
  loopCount: 0
})
```
