# {title}

`transformScale` 的 timeline 每段只支持 `toAbs`（绝对目标倍数）——没有单独的"相对开关"。所谓"相对"与"绝对"，是书写多段目标值时的两种思维：**累计写法**（以当前值为基准做增减心算）与**绝对写法**（直接写最终倍数）。需要根据场景选择合适的写法。

---

## 相对缩放（累计写法）

每个阶段的 `toAbs` 按"**以当前值为基准的增量**"心算得出：想表达"放大 2 倍""减半"这类相对意图时，用当前值乘除算出绝对目标再写入。

### 工作原理

```
本段 toAbs = 上一段实际缩放 × 想要的相对倍数
```

**示例：**

```tsx
transformScale({
  pivot: [100, 80],
  initValue: 1,
  timeline: [
    { toAbs: 2, durationSeconds: 1 },    // 1 × 2 = 2（放大 2 倍）
    { toAbs: 1, durationSeconds: 1 },    // 2 × 0.5 = 1（想"减半"，以当前值 2 为基准）
    { toAbs: 1.5, durationSeconds: 1 }   // 1 × 1.5 = 1.5（再放大 50%）
  ],
  loopCount: 0
})
```

**效果预览：**

**说明**：1x → 2x → 1x → 1.5x（无限循环）

## 绝对缩放（绝对写法）

每个阶段的 `toAbs` 直接写**最终倍数**，不做换算。

### 工作原理

```
本段 toAbs = 想要的绝对缩放值
```

**示例：**

```tsx
transformScale({
  pivot: [100, 100],
  initValue: 1,
  timeline: [
    { toAbs: 2, durationSeconds: 1 },    // 缩放到 2 倍
    { toAbs: 2, durationSeconds: 1 },    // 保持 2 倍（重复写目标值）
    { toAbs: 1.5, durationSeconds: 1 }   // 缩小到 1.5 倍
  ]
})
```

**效果预览：**

<AbsoluteMode />

**说明**：1x → 2x → 保持 2x → 1.5x

## 两种写法对比

两种写法渲染出的序列可以不同，取决于你的目标设计：

| 阶段 | 累计写法 `toAbs` | 实际缩放 | 绝对写法 `toAbs` |
|------|-------------------|---------|-------------------|
| 初始 | - | 1x | - |
| 第1段 | `2`（1 × 2） | **2x** | `2` → **2x** |
| 第2段 | `1`（2 × 0.5） | **1x** | `2` → **2x**（保持） |
| 第3段 | `1.5`（1 × 1.5） | **1.5x** | `1.5` → **1.5x** |

**效果预览对比：**

## 关键区别

### 累计写法（按增减思考时自然）

```tsx
// ✅ 想表达"减半"：以当前值 2 为基准，写出 2 × 0.5 = 1
{ toAbs: 1 }   // 当前是 2 倍，减半回到 1 倍
```

### 绝对写法（需要精确停值时直接）

```tsx
// ✅ 保持大小：重复写上一个值
{ toAbs: 2 }   // 当前是 2 倍，保持 2 倍
```

两种写法最终都落到 `toAbs` 的绝对值上，区别只在书写时的思考路径。

## 使用场景

### 场景 1：单次缩放

只有一段时两种写法完全一致，直接写目标值：

```tsx
transformScale({
  pivot: [100, 100],
  timeline: [
    { toAbs: 2, durationSeconds: 2 }
  ]
})
```

### 场景 2：往返缩放

直接写两个绝对目标，配合无限循环：

```tsx
transformScale({
  pivot: [100, 100],
  initValue: 1,
  timeline: [
    { toAbs: 1.5, durationSeconds: 1 },    // 放大到 1.5 倍
    { toAbs: 1, durationSeconds: 1 }       // 回到 1 倍
  ],
  loopCount: 0
})
```

### 场景 3：复杂路径缩放

按增减思考更直观时，逐段累计心算：

```tsx
transformScale({
  pivot: [100, 100],
  initValue: 1,
  timeline: [
    { toAbs: 1.2, durationSeconds: 1 },   // 1 × 1.2：放大到 1.2 倍
    { toAbs: 0.96, durationSeconds: 1 },  // 1.2 × 0.8：缩小 20%
    { toAbs: 1.152, durationSeconds: 1 }, // 0.96 × 1.2：再放大 20%
  ]
})
```

## 总结

| 特性 | 累计写法 | 绝对写法 |
|------|---------|---------|
| **思考路径** | 以当前值为基准做乘除 | 直接写最终倍数 |
| `toAbs` 含义 | 心算出的绝对目标 | 绝对目标 |
| `保持大小` | 重复写当前值 | 重复写当前值 |
| `适用场景` | 增减意图明确（"再放大 30%"） | 需要精确控制每个停点 |

**提示**：两种写法最终都写 `toAbs` 绝对值；多段动画建议在注释里标注每段的换算过程，方便回读。
