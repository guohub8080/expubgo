# {title}

缩放动画可以改变元素的大小，创建放大、缩小、脉冲等各种视觉效果。

---

## 放大动画

元素从原始大小放大到指定倍数。

**代码示例：**

```tsx
transformScale({
  pivot: [100, 100],
  timeline: [
    { toAbs: 2, durationSeconds: 2 }
  ]
})
```

**效果预览：**

<Enlarge />

**说明**：蓝色方块从原始大小放大到 2 倍

---

## 缩小动画

元素从原始大小缩小到指定比例。

**代码示例：**

```tsx
transformScale({
  pivot: [100, 100],
  timeline: [
    { toAbs: 0.5, durationSeconds: 2 }
  ]
})
```

**效果预览：**

<Shrink />

**说明**：绿色方块从原始大小缩小到 0.5 倍

---

## 脉冲缩放

元素快速放大后快速恢复，产生脉冲效果。

**代码示例：**

```tsx
transformScale({
  pivot: [100, 100],
  timeline: [
    { toAbs: 1.5, durationSeconds: 0.5 },
    { toAbs: 1, durationSeconds: 0.5 }
  ],
  loopCount: 0
})
```

**效果预览：**

<Pulse />

**说明**：紫色方块持续产生脉冲缩放效果

---

## 弹跳缩放

元素放大后弹回原始大小，产生弹跳效果。

**代码示例：**

```tsx
transformScale({
  pivot: [100, 100],
  timeline: [
    {
      toAbs: 1.8,
      durationSeconds: 0.8,
      keySplines: '0.68 -0.55 0.265 1.55'  // 弹性曲线
    }
  ]
})
```

**效果预览：**

<Bounce />

**说明**：橙色方块有弹性地放大到 1.8 倍后弹回

## 常用配方

常见场景直接展开为 `initValue` + `timeline` 的多段写法（`pivot` 按元素实际坐标填写）：

```tsx
import { transformScale } from "@guohub8080/expub-tool/smil";

// 简单缩放：放大到 2 倍，用时 2 秒
transformScale({
  pivot: [100, 100],
  timeline: [{ toAbs: 2, durationSeconds: 2 }]
})

// 往返缩放：0.8 ↔ 1.2，单程 1.5 秒，无限循环
transformScale({
  pivot: [100, 100],
  initValue: 1.2,
  timeline: [
    { toAbs: 0.8, durationSeconds: 1.5 },
    { toAbs: 1.2, durationSeconds: 1.5 }
  ],
  loopCount: 0
})

// 脉冲缩放：放大到 1.3 再回 1，各 0.25 秒，无限循环
transformScale({
  pivot: [100, 100],
  timeline: [
    { toAbs: 1.3, durationSeconds: 0.25 },
    { toAbs: 1, durationSeconds: 0.25 }
  ],
  loopCount: 0
})

// 弹跳缩放：放大到 1.5 倍，弹性曲线
transformScale({
  pivot: [100, 100],
  timeline: [
    { toAbs: 1.5, durationSeconds: 1, keySplines: '0.68 -0.55 0.265 1.55' }
  ]
})

// 缩放序列：1 → 1.2 → 1.5 → 1.2 → 1，每段 0.8 秒
transformScale({
  pivot: [100, 100],
  timeline: [
    { toAbs: 1, durationSeconds: 0.8 },
    { toAbs: 1.2, durationSeconds: 0.8 },
    { toAbs: 1.5, durationSeconds: 0.8 },
    { toAbs: 1.2, durationSeconds: 0.8 },
    { toAbs: 1, durationSeconds: 0.8 }
  ]
})
```

---

## 总结

| 效果 | toAbs | 使用场景 |
|------|---------|----------|
| 缩小到一半 | `0.5` | 消失效果、淡出 |
| 原始大小 | `1` | 默认值、正常状态 |
| 放大 1.2 倍 | `1.2` | 微妙强调 |
| 放大 1.5 倍 | `1.5` | 明显强调 |
| 放大 2 倍 | `2` | 重要强调 |
