# {title}

`transformScale` 是 SVG 缩放动画的核心生成工具，来自 `@guohub8080/expub-tool/smil`。本文将介绍函数签名、核心概念，并通过基础示例展示其基本用法。

---

## 函数签名

```tsx
import { transformScale } from '@guohub8080/expub-tool/smil';

transformScale({
  // ===== 必填参数 =====
  timeline: ScaleTimelineSegment[],         // 必填：时间线段数组
  pivot: [number, number],                  // 必填：缩放中心点坐标 [x, y]

  // ===== 可选参数 =====
  initValue?: number,                        // 初始缩放，默认 1
  begin?: string,                            // 开始时机：'2s' 延迟自动开始；'click' 点击触发；'click+0.5s' 点击后延迟
  isAdditive?: boolean,                      // 是否累加变换，默认 true
  calcMode?: 'spline' | 'linear' | 'discrete' | 'paced',  // 动画计算模式，自动
  isFreeze?: boolean,                        // 是否保持最终状态，默认 false
  loopCount?: number,                        // 循环次数（0 = 无限），默认 1
  native?: T_NativeAnimateTransform,         // 透传/覆盖原生 animateTransform 属性（最后展开，同名覆盖生成值）
})
```

---

## 核心概念

### 初始缩放（initValue）

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `initValue` | `number` | `1` | 初始缩放值（可选）|

### 时间线段

这是最核心的参数，定义动画的每个阶段。

**ScaleTimelineSegment 类型：**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `toAbs` | `number` | 上一段缩放值 | 目标缩放值（绝对倍数，1 = 原大小） |
| `durationSeconds` | `number` | 必填 | 该段持续时间（秒）|
| `keySplines` | `string` | 线性 | 贝塞尔缓动参数（可选）|

### 缩放中心点（pivot）

`pivot` 为**必填**参数，格式为坐标数组 `[x, y]`。缩放围绕该坐标进行：想让元素"原地"放大缩小，就按元素几何位置算出中心坐标写入（详见「缩放中心点」一章）。

---

## 缩放值说明

| 值 | 效果 |
|------|------|
| `0.5` | 缩小到一半 |
| `1` | 原始大小（默认）|
| `2` | 放大 2 倍 |
| `3` | 放大 3 倍 |

---

## 基本用法

创建一个放大 2 倍的方块。

**代码示例：**

```tsx
import { transformScale } from "@guohub8080/expub-tool/smil";

<svg width="200" height="200" viewBox="0 0 200 200">
  <rect x="75" y="75" width="50" height="50" fill="blue">
    {transformScale({
      pivot: [100, 100],
      timeline: [
        { toAbs: 2, durationSeconds: 2 }
      ]
    })}
  </rect>
</svg>
```

## 常用默认值

`transformScale` 的设计让大多数参数都有合理的默认值，让你能快速创建动画。

- **绝对目标写法**（`toAbs`）
  - 每段 `toAbs` 都是绝对目标倍数，语义直观
  - 多段动画中"保持大小"直接重复上一值
  - 想表达"以当前值为基准增减"时，按累计心算写出目标值即可（详见「相对缩放与绝对缩放」一章）

- **累加模式**（`isAdditive: true`）
  - 可以与旋转、位移动画同时进行
  - 自动叠加到其他变换上
