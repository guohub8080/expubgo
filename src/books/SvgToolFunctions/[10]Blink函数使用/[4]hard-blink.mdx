# {title}

`animateHardBlink` 生成硬闪烁效果，与软闪烁不同，硬闪烁在完全透明（opacity: 0）和完全不透明（opacity: 1）之间直接切换，没有渐变过渡。

---

## 硬闪烁 vs 软闪烁

| 特性 | 软闪烁（Soft Blink） | 硬闪烁（Hard Blink） |
|------|---------------------|---------------------|
| **过渡方式** | 平滑渐变 | 直接切换 |
| **透明度范围** | 可自定义（如 1 → 0.2 → 1） | 固定（1 → 0 → 1） |
| **缓动曲线** | 支持（ease-in-out 等） | 不支持（discrete 模式） |
| **视觉效果** | 类似呼吸灯 | 类似霓虹灯/警示灯 |
| **适用场景** | 装饰、柔和提示 | 警示、紧急信号 |
| **时间控制** | 单个时长参数 | 点亮段 + 熄灭段两段时长 |

---

## 函数签名

```tsx
import { animateHardBlink } from '@guohub8080/expub-tool/behaviors';

animateHardBlink({
  onDurationSeconds?: number,      // 默认 0.8：0→1（点亮）段时长（秒）
  offDurationSeconds?: number,     // 默认 0.3：1→0（熄灭）段时长（秒）
  begin?: string,                  // 默认 undefined：开始时机（'2s' / 'click' / 'click+0.5s'）
  loopCount?: number,              // 默认 0：循环次数（0 = 无限）
})
```

## 基础用法

### 标准硬闪烁

**代码示例：**

```tsx
import { animateHardBlink } from "@guohub8080/expub-tool/behaviors";

<svg width="200" height="200" viewBox="0 0 200 200">
```

```xml
<animate
  attributeName="opacity"
  values="1; 0; 1"
  keyTimes="0; 0.273; 1"
  dur="1.1s"
  repeatCount="indefinite"
  calcMode="discrete"
/>
```

**说明：** 星星以 1.1 秒（0.3s + 0.8s）为周期在点亮与熄灭之间直接切换，无渐变效果。

## 参数详解

### onDurationSeconds / offDurationSeconds

这两个参数组成 `values="1;0;1"` 时间线的两段：

| 参数 | 说明 | 默认值 | 推荐值 |
|------|------|--------|--------|
| `onDurationSeconds` | 0→1（点亮）段的时长 | `0.8` | 0.3-2.0 |
| `offDurationSeconds` | 1→0（熄灭）段的时长 | `0.3` | 0.2-1.0 |

**计算公式：**

```
总周期时长 = onDurationSeconds + offDurationSeconds
keyTimes 中间点 = offDurationSeconds / 总周期时长
```

**示例：**

```tsx
// 快速节奏
animateHardBlink({
  onDurationSeconds: 0.3,
  offDurationSeconds: 0.3  // 总周期 0.6s
})

// 慢速节奏
animateHardBlink({
  onDurationSeconds: 2,
  offDurationSeconds: 0.5  // 总周期 2.5s
})

// 偶尔闪烁
animateHardBlink({
  onDurationSeconds: 0.2,
  offDurationSeconds: 3    // 总周期 3.2s
})
```

## 时序控制

硬闪烁支持与软闪烁相同的时序控制选项。

### 有限次数闪烁

**代码示例：**

```tsx
{animateHardBlink({
  onDurationSeconds: 0.6,
  offDurationSeconds: 0.4,
  loopCount: 5  // 闪烁 5 次后停止
})}
```

**说明：** 闪烁 5 次后停止。

---

### 点击触发

**代码示例：**

```tsx
<svg>
  <g style={{ cursor: 'pointer' }}>
    <rect width="200" height="200" fill="transparent" />
    <circle cx="100" cy="100" r="50" fill="red">
      {animateHardBlink({
        begin: 'click'
      })}
    </circle>
  </g>
</svg>
```

**说明：** 点击后开始硬闪烁。

---

### 延迟启动

**代码示例：**

```tsx
{animateHardBlink({
  onDurationSeconds: 0.8,
  offDurationSeconds: 0.3,
  begin: '2s'  // 延迟 2 秒后开始
})}
```

## 软硬闪烁对比示例

同一个元素使用软闪烁和硬闪烁的效果对比：

```tsx
  minOpacity: 0,
  onceBlinkDurationSeconds: 1.2
})}
```

**效果：** 透明度从 1 平滑过渡到 0，再平滑过渡回 1（类似呼吸灯）

```tsx
{animateHardBlink({
  onDurationSeconds: 0.8,
  offDurationSeconds: 0.4
})}
```

**效果：** 直接在显示和隐藏之间切换（类似开关灯）

## 选择建议

### 使用软闪烁（Soft Blink）的场景：

- ✅ 装饰性元素（星星、光晕等）
- ✅ 柔和的提示（加载状态、待处理事项）
- ✅ 呼吸效果（氛围营造）
- ✅ 需要平滑过渡的动画

### 使用硬闪烁（Hard Blink）的场景：

- ✅ 警示提示（警告、错误）
- ✅ 紧急信号（SOS、危险提示）
- ✅ 霓虹灯效果（招牌、标识）
- ✅ 需要强烈视觉冲击的场景
