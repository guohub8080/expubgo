# {title}

`transformBreathe` 是专门用于创建呼吸动画效果的行为动画工具。呼吸动画是一种自动循环的缩放效果，模拟生物呼吸的节奏，常用于吸引注意力、提示重要信息、营造氛围等场景。

---

## 函数签名

```tsx
import { transformBreathe } from '@guohub8080/expub-tool/behaviors';

transformBreathe({
  fromScale?: number,                    // 默认 1：初始缩放比例
  toScale?: number,                      // 默认 1.1：目标缩放比例
  onceBreatheDurationSeconds?: number,   // 默认 2：一次呼吸时长（秒）
  pivot: [number, number],               // 必填：缩放支点坐标 [x, y]
  keySplines?: string,                   // 默认 '0.42 0 0.58 1'：缓动曲线
  begin?: string,                        // 默认 undefined：开始时机（'2s' / 'click' / 'click+0.5s'）
  loopCount?: number,                    // 默认 0：循环次数（0 = 无限）
})
```

---

## 核心概念

### 什么是呼吸动画？

呼吸动画是一种平滑的缩放动画，模拟生物呼吸的节奏：
- **放大阶段**：从 `fromScale` 增大到 `toScale`
- **缩小阶段**：从 `toScale` 回到 `fromScale`
- **循环播放**：自动无限循环（可配置次数）

### 参数详解

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `fromScale` | `number` | `1` | 初始缩放比例 |
| `toScale` | `number` | `1.1` | 目标缩放比例 |
| `onceBreatheDurationSeconds` | `number` | `2` | 一次呼吸时长（秒）|
| `pivot` | `[number, number]` | **必填** | 缩放支点坐标 `[x, y]`（通常写元素中心）|
| `keySplines` | `string` | `'0.42 0 0.58 1'` | 缓动曲线 |
| `begin` | `string` | `undefined` | 开始时机：`'2s'`（延迟自动开始）、`'click'`、`'click+0.5s'` |
| `loopCount` | `number` | `0` | 循环次数（0 = 无限）|

## 基本用法

### 最简单的呼吸效果

使用默认参数创建标准呼吸效果（`pivot` 是唯一必填项）。

**代码示例：**

```tsx
import { transformBreathe } from "@guohub8080/expub-tool/behaviors";

<svg width="200" height="200" viewBox="0 0 200 200">
  <g>
    {transformBreathe({ pivot: [100, 100] })}
    <circle cx="100" cy="100" r="50" fill="blue" />
  </g>
</svg>
```

## 常用配方

新 API 不再提供呼吸预设对象，直接把常用节奏写成参数字面量即可（数值沿用旧预设语义）：

```tsx
import { transformBreathe } from '@guohub8080/expub-tool/behaviors';

// 标准呼吸（2 秒）
transformBreathe({ pivot: [100, 100] })

// 快速呼吸（1 秒，幅度 1.15）
transformBreathe({ onceBreatheDurationSeconds: 1, toScale: 1.15, pivot: [100, 100] })

// 慢速呼吸（3 秒，幅度 1.08）
transformBreathe({
  onceBreatheDurationSeconds: 3,
  toScale: 1.08,
  keySplines: '0.37 0 0.63 1',
  pivot: [100, 100]
})

// 轻微呼吸（2.5 秒，小幅度 1.05）
transformBreathe({ onceBreatheDurationSeconds: 2.5, toScale: 1.05, pivot: [100, 100] })

// 强烈呼吸（1.5 秒，大幅度 1.2）
transformBreathe({ onceBreatheDurationSeconds: 1.5, toScale: 1.2, pivot: [100, 100] })

// 延迟呼吸（延迟 1 秒后开始）
transformBreathe({ begin: '1s', pivot: [100, 100] })
```

## pivot 支点设置

新 API 不再依赖 CSS `transformOrigin`/`transformBox` 配合，而是通过必填的 `pivot: [x, y]` 显式声明缩放支点（SVG 用户坐标）。想让元素围绕自身中心呼吸，直接写元素中心坐标即可。

### 写元素中心坐标

圆 `<circle cx="100" cy="100" r="50" />` 的中心就是 `(100, 100)`：

```tsx
import { transformBreathe } from "@guohub8080/expub-tool/behaviors";

<svg width="200" height="200" viewBox="0 0 200 200">
  <g>
    {transformBreathe({ pivot: [100, 100] })}
    <circle cx="100" cy="100" r="50" fill="blue" />
  </g>
</svg>
```

### 生成原理

`transformBreathe` 内部基于 `transformScale` 的时间线实现，`pivot` 会被编译为三个 `additive="sum"` 的 `animateTransform`（平移到支点 → 缩放 → 平移回来），因此无需任何 CSS 配合：

```xml
<!-- 平移到支点 -->
<animateTransform attributeName="transform" type="translate"
  values="100 100;100 100;100 100" keyTimes="0;0.5;1" dur="2s"
  calcMode="linear" additive="sum" repeatCount="indefinite" />
<!-- 围绕支点缩放 -->
<animateTransform attributeName="transform" type="scale"
  values="1 1;1.1 1.1;1 1" keyTimes="0;0.5;1" keySplines="0.42 0 0.58 1;0.42 0 0.58 1"
  dur="2s" calcMode="spline" additive="sum" repeatCount="indefinite" />
<!-- 平移回来 -->
<animateTransform attributeName="transform" type="translate"
  values="-100 -100;-100 -100;-100 -100" keyTimes="0;0.5;1" dur="2s"
  calcMode="linear" additive="sum" repeatCount="indefinite" />
```

### 常见形状的中心求法

| 形状 | 中心坐标 |
|------|---------|
| `<circle cx="100" cy="100" r="50" />` | `pivot: [100, 100]`（即 cx、cy）|
| `<rect x="50" y="60" width="100" height="80" />` | `pivot: [100, 100]`（x + width/2，y + height/2）|
| `<path>` / 任意图形 | 取包围盒对角线中点，或按 viewBox 目测估算 |

## 注意事项

### 1. 必须设置 pivot

`pivot` 是 `transformBreathe` 唯一必填的参数，缺了它 TypeScript 会直接报错。

**✅ 正确：**

```tsx
<g>
  {transformBreathe({ pivot: [100, 100] })}
  <circle cx="100" cy="100" r="50" fill="blue" />
</g>
```

**❌ 错误：**

```tsx
<g>
  {transformBreathe()}
  <circle cx="100" cy="100" r="50" fill="blue" />
</g>
```

---

### 2. 与其他动画的组合

`transformBreathe` 生成的变换默认以 `additive="sum"` 叠加，可与旋转等其他变换动画直接共存：

```tsx
// 呼吸 + 旋转叠加
<g>
  {transformBreathe({ pivot: [100, 100] })}
  {transformRotate({
    timeline: [{ toAbs: 45, durationSeconds: 2 }],
    pivot: [100, 100]
  })}
  <rect width="100" height="100" fill="red" />
</g>
```

---

### 3. 呼吸效果建议

- **装饰元素**：使用小幅度（1.05-1.08）+ 慢速（2-3秒）
- **提示信息**：使用中幅度（1.1-1.15）+ 中速（1.5-2秒）
- **重要强调**：使用大幅度（1.2）+ 快速（1秒）
